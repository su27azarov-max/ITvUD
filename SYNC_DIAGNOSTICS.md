# Диагностика проблем с синхронизацией GitHub

## 🔍 Быстрая проверка

### Шаг 1: Проверьте консоль браузера

1. Откройте сайт
2. Нажмите **F12** (или Ctrl+Shift+I)
3. Перейдите на вкладку **Console**
4. Попробуйте сохранить данные
5. Посмотрите на сообщения:

**Ожидаемые сообщения при успешном сохранении:**
```
📡 Запрос к GitHub для записи: https://api.github.com/repos/...
📝 Файл существует, SHA: ...
📤 Отправка данных в GitHub...
📥 Ответ GitHub: 200 OK
✅ Данные сохранены в GitHub
📝 Commit: ...
```

**Сообщения при ошибках:**
```
❌ Ошибка чтения из GitHub: ...
❌ Ошибка записи в GitHub: ...
```

### Шаг 2: Проверьте настройки GitHub

1. Войдите как преподаватель
2. Нажмите **"⚙️ GitHub"**
3. Проверьте все поля:
   - **Владелец**: точно как на GitHub (без пробелов)
   - **Репозиторий**: точно как на GitHub (без пробелов)
   - **Token**: начинается с `ghp_` или `github_pat_`
   - **Путь**: `data.json`
   - **Ветка**: `main`

### Шаг 3: Протестируйте соединение

1. Нажмите **"🔍 Тест"** в окне настроек GitHub
2. Посмотрите результат:
   - ✅ "Соединение с GitHub работает!" - всё хорошо
   - ❌ Ошибка - следуйте инструкциям

## 🐛 Частые проблемы и решения

### Проблема 1: "Неверный токен GitHub"

**Симптомы:**
```
❌ Ошибка записи в GitHub: Неверный токен GitHub
```

**Причина:** Токен недействителен, истёк или введён неправильно.

**Решение:**
1. Перейдите на https://github.com/settings/tokens
2. Проверьте срок действия токена
3. Если истёк - создайте новый
4. Убедитесь, что токен имеет права **`repo`**
5. Скопируйте токен заново (начинается с `ghp_...`)
6. Вставьте в настройки GitHub

**Проверка в консоли:**
```javascript
const config = JSON.parse(localStorage.getItem('github_config'));
console.log('Токен начинается с:', config.token.substring(0, 10));
console.log('Длина токена:', config.token.length);
// Должно быть: ghp_... и длина ~40 символов
```

### Проблема 2: "Доступ запрещён"

**Симптомы:**
```
❌ Ошибка записи в GitHub: Доступ запрещён. Проверьте права токена
```

**Причина:** Токен не имеет необходимых прав.

**Решение:**
1. Перейдите на https://github.com/settings/tokens
2. Нажмите на ваш токен
3. Убедитесь, что отмечен чекбокс **`repo`** (полный доступ)
4. Если нет - создайте новый токен с правильными правами

**Альтернатива (Fine-grained token):**
1. Выберите "Fine-grained token"
2. Укажите только нужный репозиторий
3. Дайте права: **Contents** → Read and write

---

### Проблема 3: "Репозиторий не найден"

**Симптомы:**
```
❌ Ошибка записи в GitHub: Репозиторий не найден
```

**Причина:** Неправильно указано имя владельца или репозитория.

**Решение:**
1. Откройте репозиторий на GitHub
2. Посмотрите URL: `https://github.com/ВЛАДЕЛЕЦ/РЕПОЗИТОРИЙ`
3. Убедитесь, что в настройках GitHub указано точно так же
4. Проверьте регистр (GitHub чувствителен к регистру!)

**Пример:**
```
URL: https://github.com/ivanov/rating-system
Владелец: ivanov (НЕ Ivanov, не IVANOV)
Репозиторий: rating-system (НЕ Rating-System)
```

---

### Проблема 4: "Файл data.json не найден"

**Симптомы:**
```
ℹ️ Файл data.json не найден в репозитории
```

**Причина:** Файл `data.json` не существует в репозитории.

**Решение:**

**Вариант 1: Создать вручную**
1. Откройте репозиторий на GitHub
2. Нажмите "Add file" → "Create new file"
3. Введите имя: `data.json`
4. Вставьте начальное содержимое:
```json
{
  "students": [],
  "categories": [],
  "lastUpdated": ""
}
```
5. Нажмите "Commit new file"

**Вариант 2: Автоматическое создание**
1. Внесите любые изменения в приложении
2. Нажмите "💾 Сохранить"
3. Файл создастся автоматически

---

### Проблема 5: CORS ошибка

**Симптомы:**
```
Access to fetch at 'https://api.github.com/...' from origin '...' has been blocked by CORS policy
```

**Причина:** GitHub API блокирует запросы из-за политики CORS.

**Решение:**
1. Убедитесь, что используете HTTPS (GitHub Pages автоматически использует HTTPS)
2. Очистите кэш браузера (Ctrl+Shift+Delete)
3. Попробуйте другой браузер
4. Проверьте, что токен действителен

**Если проблема сохраняется:**
- GitHub API должен поддерживать CORS для авторизованных запросов
- Возможно, проблема с сетью или провайдером
- Попробуйте использовать VPN

---

### Проблема 6: Данные не обновляются на другом устройстве

**Симптомы:** Изменения на первом устройстве не видны на втором.

**Причина:** Данные не сохраняются в GitHub или не загружаются на втором устройстве.

**Решение:**

**На первом устройстве:**
1. Внесите изменения
2. Нажмите "💾 Сохранить"
3. Дождитесь сообщения "✅ Изменения сохранены в GitHub"
4. Проверьте в консоли (F12), что нет ошибок
5. Откройте репозиторий на GitHub и проверьте, что файл `data.json` обновился

**На втором устройстве:**
1. Откройте сайт
2. Нажмите "🔄 Синхронизация"
3. Или обновите страницу (F5)
4. Проверьте в консоли (F12), что данные загружены из GitHub

**Проверка в консоли:**
```javascript
// На первом устройстве после сохранения:
console.log('Последнее сохранение:', new Date().toISOString());

// На втором устройстве:
const config = JSON.parse(localStorage.getItem('github_config'));
console.log('GitHub настроен:', !!config.token);
```

### Проблема 7: "Ошибка валидации"

**Симптомы:**
```
❌ Ошибка записи в GitHub: Ошибка валидации
```

**Причина:** Неправильный формат данных или SHA файла.

**Решение:**
1. Очистите localStorage:
```javascript
// В консоли браузера (F12):
localStorage.clear();
```
2. Обновите страницу (F5)
3. Попробуйте сохранить снова

## 🔧 Диагностика через консоль

### Проверка конфигурации GitHub

```javascript
// Проверка конфигурации
const config = JSON.parse(localStorage.getItem('github_config'));
console.log('Конфигурация GitHub:', config);

// Проверка токена
if (config && config.token) {
    console.log('✅ Токен установлен');
    console.log('Токен начинается с:', config.token.substring(0, 10) + '...');
    console.log('Длина токена:', config.token.length);
} else {
    console.log('❌ GitHub не настроен');
}
```

### Проверка данных

```javascript
// Проверка данных
console.log('Курсантов:', students.length);
console.log('Категорий:', categories.length);
console.log('Первый курсант:', students[0]);

// Проверка расчёта баллов
if (students.length > 0) {
    console.log('Баллы первого курсанта:', calcTotal(students[0]));
    console.log('Максимум:', getMaxTotal());
}
```

### Ручное тестирование GitHub API

```javascript
// Тест чтения из GitHub
async function testRead() {
    const config = JSON.parse(localStorage.getItem('github_config'));
    const url = `https://api.github.com/repos/${config.owner}/${config.repo}/contents/${config.filePath}`;
    
    try {
        const response = await fetch(url, {
            headers: {
                'Authorization': `Bearer ${config.token}`,
                'Accept': 'application/vnd.github.v3+json'
            }
        });
        
        console.log('Статус:', response.status);
        
        if (response.ok) {
            const data = await response.json();
            console.log('✅ Файл найден');
            console.log('SHA:', data.sha);
            console.log('Размер:', data.size, 'байт');
        } else {
            console.log('❌ Ошибка:', response.statusText);
        }
    } catch (error) {
        console.error('❌ Ошибка:', error);
    }
}

testRead();
```

## 📊 Проверка файла на GitHub

### Шаг 1: Откройте репозиторий

1. Перейдите на `https://github.com/ВЛАДЕЛЕЦ/РЕПОЗИТОРИЙ`
2. Найдите файл `data.json`
3. Нажмите на него

### Шаг 2: Проверьте содержимое

Файл должен содержать:
```json
{
  "students": [...],
  "categories": [...],
  "lastUpdated": "2026-01-15T..."
}
```

### Шаг 3: Проверьте последнее обновление

1. Нажмите на "Commits" (История коммитов)
2. Найдите последний коммит с сообщением "Обновление данных рейтинга курсантов"
3. Проверьте дату и время

- [ ] Консоль браузера открыта (F12)

## 📞 Если ничего не помогло

### Соберите информацию:

1. **Скриншот настроек GitHub** (скройте токен!)
2. **Скриншот консоли браузера** (F12 → Console)
3. **URL репозитория** на GitHub
4. **Текст ошибки** из консоли

### Попробуйте:

1. **Очистить все данные:**
```javascript
localStorage.clear();
location.reload();
```

   - Generate new token (classic)
   - Отметить `repo`
   - Скопировать и вставить

3. **Создать новый репозиторий:**
   - https://github.com/new
   - Public
   - Add README
   - Создать файл `data.json`

4. **Использовать альтернативу:**
   - Ручной экспорт/импорт (кнопки "💾 Экспорт" и "📂 Загрузить")
   - Firebase Realtime Database (инструкция в `FIREBASE_SETUP.md`)
