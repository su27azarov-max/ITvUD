# 🔧 Диагностика и исправление конфликта версий

## 🎯 Проблема

Возникает ошибка:
```
Ошибка: Конфликт версий. Файл был изменён. Попробуйте ещё раз.
Данные сохранены локально.
```

И в файле `data.json` присутствует совсем другой код.

## 🔍 Причина проблемы

Система записывает данные в файл, указанный в настройках GitHub (`GITHUB_CONFIG.filePath`). 

**Возможные причины:**

1. **В настройках GitHub указан другой путь к файлу**
   - Например: `docs/data.json` вместо `data.json`
   - Или: `rating-data.json` вместо `data.json`

2. **Файл был изменён вручную на GitHub**
   - Кто-то отредактировал файл через веб-интерфейс
   - Или через другой инструмент

3. **Несколько устройств работают одновременно**
   - Преподаватель сохраняет данные с разных компьютеров
   - Возникает конфликт версий

## 🛠️ Диагностика

### Шаг 1: Проверьте настройки GitHub

1. Откройте сайт
2. Войдите как преподаватель (пароль: `05072020`)
3. Нажмите **"⚙️ GitHub"**
4. Проверьте поле **"Путь к файлу данных"**

**Должно быть:** `data.json`

**Если указано что-то другое:**
- Измените на `data.json`
- Нажмите **"Сохранить"**

### Шаг 2: Проверьте файл data.json на GitHub

1. Откройте репозиторий на GitHub
2. Найдите файл `data.json` в **корне репозитория**
3. Проверьте его содержимое

**Правильная структура:**
```json
{
  "students": [
    {
      "id": 1,
      "fullName": "Иванов Иван Сергеевич",
      "group": "1 взвод",
      "notes": 0,
      "practice": 0,
      "reports": 0,
      "bonus": 0,
      "testing": 0,
      "notesGrades": {"3": 0, "4": 0, "5": 0},
      "practiceGrades": {"3": 0, "4": 0, "5": 0},
      "reportsGrades": {"3": 0, "4": 0, "5": 0},
      "testingGrades": {"3": 0, "4": 0, "5": 0}
    }
  ],
  "categories": [...],
  "lastUpdated": "2026-01-15T10:00:00.000Z"
}
```

### Шаг 3: Проверьте консоль браузера

1. Нажмите **F12** (или Ctrl+Shift+I)
2. Перейдите на вкладку **Console**
3. Попробуйте сохранить данные
4. Посмотрите логи:

**Правильные логи:**
```
📡 Попытка 1/3 записи в GitHub...
📝 Файл существует, SHA: abc123...
📤 Отправка данных в GitHub...
📥 Ответ GitHub: 200 OK
✅ Данные сохранены в GitHub
📝 Commit: xyz789...
```

**Если видите другое:**
- Скопируйте текст ошибки
- Проверьте URL в логах

### Шаг 4: Проверьте localStorage

1. Откройте консоль браузера (F12)
2. Введите команду:
```javascript
const config = JSON.parse(localStorage.getItem('github_config'));
console.log('Настройки GitHub:', config);
```

**Что должно быть:**
```javascript
{
  owner: "ваш-username",
  repo: "ваш-репозиторий",
  token: "ghp_...",
  filePath: "data.json",  // ← ВАЖНО!
  branch: "main"
}
```

**Если `filePath` другой:**
- Это причина проблемы!
- Измените настройки через интерфейс "⚙️ GitHub"

## 🔧 Исправление

### Решение 1: Исправить настройки GitHub

1. Откройте сайт
2. Войдите как преподаватель
3. Нажмите **"⚙️ GitHub"**
4. Измените поле **"Путь к файлу данных"** на: `data.json`
5. Нажмите **"Сохранить"**
6. Нажмите **"🔍 Тест"** для проверки
7. Нажмите **"💾 Сохранить"** для записи данных

### Решение 2: Очистить localStorage и начать заново

Если настройки повреждены:

1. Откройте консоль браузера (F12)
2. Введите команды:
```javascript
localStorage.clear();
location.reload();
```
3. Снова настройте GitHub через "⚙️ GitHub"
4. Убедитесь, что путь указан как `data.json`

## 💡 Профилактика конфликтов

### Рекомендация 1: Избегайте одновременной работы

- Если несколько преподавателей работают с системой:
  - Договоритесь о порядке сохранения
  - Сохраняйте по очереди
  - Используйте синхронизацию перед началом работы

### Рекомендация 2: Сохраняйте регулярно

- Не накапливайте много изменений
- Сохраняйте после каждого значимого изменения
- Это снижает вероятность конфликтов

### Рекомендация 3: Проверяйте настройки

- Периодически проверяйте настройки GitHub
- Убедитесь, что путь указан как `data.json`
- Проверьте, что токен действителен

### Рекомендация 4: Делайте резервные копии

- Используйте кнопку **"💾 Экспорт"**
- Сохраняйте JSON файл в надёжное место
- При необходимости можно импортировать данные обратно
