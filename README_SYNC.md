## 🔍 Диагностика

### Страница диагностики
Откройте: `docs/check-sync.html`

Эта страница автоматически проверит:
- ✅ Настройки GitHub
- ✅ Соединение с GitHub
- ✅ Наличие файла data.json
- ✅ Чтение и запись данных

### Консоль браузера
Нажмите F12 и введите:
```javascript
// Проверка настроек
const config = JSON.parse(localStorage.getItem('github_config'));
console.log('Настройки GitHub:', config);

// Тест соединения
async function test() {
    const url = `https://api.github.com/repos/${config.owner}/${config.repo}`;
    const response = await fetch(url, {
        headers: {
            'Authorization': `Bearer ${config.token}`,
            'Accept': 'application/vnd.github.v3+json'
        }
    });
    console.log('Соединение:', response.ok ? '✅' : '❌');
}
test();
```

## 🐛 Частые проблемы

### Проблема: "GitHub не настроен"
**Решение:** Нажмите "⚙️ GitHub" и заполните все поля.

### Проблема: "Неверный токен"
**Решение:** Создайте новый токен на https://github.com/settings/tokens с правами `repo`.

### Проблема: "Репозиторий не найден"
**Решение:** Проверьте имя владельца и репозитория (регистр важен!).

### Проблема: "Файл не найден"
**Решение:** Создайте файл `data.json` в репозитории или нажмите "💾 Сохранить".
