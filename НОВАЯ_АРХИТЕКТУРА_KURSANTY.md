# 📋 Новая архитектура с файлом kursanty.json

## 🎯 Что изменилось?

Вместо сложной синхронизации через GitHub API, теперь система использует **простой файл `kursanty.json`** для хранения данных курсантов.

### Преимущества новой архитектуры:

1. ✅ **Простота** - один файл с данными курсантов
2. ✅ **Надёжность** - нет конфликтов версий
3. ✅ **Скорость** - быстрая загрузка данных
4. ✅ **Удобство** - можно редактировать файл вручную
5. ✅ **Совместимость** - поддержка старого формата `data.json`

---

## 📁 Структура файла kursanty.json

```json
{
  "kursanty": [
    {
      "id": 1,
      "fullName": "Иванов Иван Сергеевич",
      "group": "1 взвод",
      "notes": 0,
      "practice": 0,
      "reports": 0,
      "bonus": 0,
      "testing": 0,
      "notesGrades": {"3": 0, "4": 0, "5": 0},
      "practiceGrades": {"3": 0, "4": 0, "5": 0},
      "reportsGrades": {"3": 0, "4": 0, "5": 0},
      "testingGrades": {"3": 0, "4": 0, "5": 0}
    },
    {
      "id": 2,
      "fullName": "Петрова Анна Михайловна",
      "group": "1 взвод",
      "notes": 0,
      "practice": 0,
      "reports": 0,
      "bonus": 0,
      "testing": 0,
      "notesGrades": {"3": 0, "4": 0, "5": 0},
      "practiceGrades": {"3": 0, "4": 0, "5": 0},
      "reportsGrades": {"3": 0, "4": 0, "5": 0},
      "testingGrades": {"3": 0, "4": 0, "5": 0}
    }
  ],
  "lastUpdated": "2026-01-15T10:00:00.000Z",
  "version": "1.0"
}
```

### Поля файла:

- **`kursanty`** - массив курсантов
- **`lastUpdated`** - дата последнего обновления
- **`version`** - версия формата файла

### Поля каждого курсанта:

- **`id`** - уникальный идентификатор
- **`fullName`** - ФИО курсанта
- **`group`** - взвод (например: "1 взвод", "2 взвод", "3 взвод")
- **`notes`** - баллы за конспекты
- **`practice`** - баллы за практические работы
- **`reports`** - баллы за доклады
- **`bonus`** - дополнительные баллы
- **`testing`** - баллы за тестирование
- **`notesGrades`** - количество оценок за конспекты (3, 4, 5)
- **`practiceGrades`** - количество оценок за практики (3, 4, 5)
- **`reportsGrades`** - количество оценок за доклады (3, 4, 5)
- **`testingGrades`** - количество оценок за тестирование (3, 4, 5)

## 🚀 Как пользоваться?

### Способ 1: Через интерфейс сайта (рекомендуется)

#### Добавление курсантов:

1. **Войдите как преподаватель** (пароль: `05072020`)

2. **Добавьте одного курсанта:**
   - Нажмите **"➕ Добавить"**
   - Введите ФИО курсанта
   - Введите название взвода (например: "1 взвод")
   - Нажмите **"Сохранить"**

3. **Или импортируйте список:**
   - Нажмите **"📥 Импорт"**
   - Вставьте список в формате:
     ```
     # 1 взвод
     Иванов Иван Сергеевич
     Петрова Анна Михайловна
     Сидоров Алексей Дмитриевич
     
     # 2 взвод
     Морозова Елена Викторовна
     Волков Артём Николаевич
     Соколова Дарья Олеговна
     
     # 3 взвод
     Попов Никита Александрович
     Васильева Татьяна Петровна
     Зайцев Роман Владимирович
     ```
   - Нажмите **"Импортировать"**

4. **Экспортируйте данные:**
   - Нажмите **"💾 Экспорт"**
   - Скачается файл `kursanty-2026-01-15.json`
   - Загрузите этот файл в репозиторий на GitHub

#### Начисление баллов:

1. Нажмите **"✏️ Баллы"** рядом с именем курсанта
2. Выберите категорию
3. Добавьте оценки или баллы
4. Нажмите **"Сохранить"**

### Способ 2: Редактирование файла kursanty.json

1. Откройте репозиторий на GitHub
2. Найдите файл `kursanty.json`
3. Нажмите иконку карандаша для редактирования
4. Добавьте новых курсантов в массив `kursanty`
5. Сохраните изменения (Commit)

## 📊 Сравнение старой и новой архитектуры

### Старая архитектура (data.json):

```
┌─────────────────────────────────────────────────────────┐
│                    Браузер (сайт)                        │
│                                                          │
│  1. Загрузка данных из data.json                        │

│  PUT /repos/{owner}/{repo}/contents/data.json           │
│  {                                                      │
│    "students": [...],                                   │
│    "categories": [...],                                 │
```

**Проблемы:**
- ❌ Конфликты версий (HTTP 409)
- ❌ Сложная синхронизация

- ❌ Ошибки при сохранении

```
┌─────────────────────────────────────────────────────────┐
│                    Браузер (сайт)                        │
│                                                          │
│  1. Загрузка данных из kursanty.json                    │

│  3. Изменения в памяти                                  │

│  5. Загрузка файла в репозиторий                        │
└─────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────┐
│              Файл kursanty.json (репозиторий)           │
│                                                          │
│  {                                                      │
│    "kursanty": [...],                                   │

│    "version": "1.0"                                     │
│  }                                                      │

```

**Преимущества:**
- ✅ Нет конфликтов версий
- ✅ Простая синхронизация
- ✅ Не нужен токен GitHub для чтения

## 🐛 Решение проблем

### Проблема: Данные не загружаются

**Решение:**
1. Проверьте, что файл `kursanty.json` существует в репозитории
2. Проверьте, что файл содержит правильный JSON
3. Нажмите **"🔄 Синхронизация"**
4. Очистите кэш браузера (Ctrl+Shift+Delete)

### Проблема: Ошибка при импорте

**Решение:**
1. Проверьте формат файла
2. Убедитесь, что файл содержит поле `kursanty` или `students`
3. Проверьте, что массив не пустой
4. Попробуйте экспортировать данные заново

### Проблема: Данные не сохраняются

**Решение:**
1. Нажмите **"💾 Экспорт"** для создания файла
2. Загрузите файл в репозиторий на GitHub
3. Дождитесь обновления GitHub Pages (1-2 минуты)
4. Нажмите **"🔄 Синхронизация"**
