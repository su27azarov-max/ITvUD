# 🔍 Диагностика проблемы с токеном GitHub (ошибка 401)

## 🎯 Проблема

Токен новый и действительный до 5 декабря, но GitHub API возвращает ошибку 401 (Unauthorized).

## 🔧 Возможные причины

### 1. Токен не имеет прав `repo`

**Как проверить:**
1. Откройте https://github.com/settings/tokens
2. Нажмите на ваш токен
3. Проверьте раздел "Select scopes"
4. Должен быть отмечен чекбокс **`repo`** (полный доступ к репозиториям)

**Решение:**
Если чекбокс `repo` не отмечен:
1. Удалите старый токен
2. Создайте новый токен
3. Отметьте чекбокс **`repo`**
4. Скопируйте новый токен

### 2. Токен скопирован неправильно

**Как проверить:**
1. Откройте консоль браузера (F12)
2. Вставьте код из файла `docs/diagnose-token.js`
3. Нажмите Enter
4. Посмотрите результат

**Что должно быть:**
- ✅ Токен начинается с `ghp_` или `github_pat_`
- ✅ Токен не содержит пробелов
- ✅ Токен не содержит переносов строк
- ✅ Длина токена ~40 символов

**Решение:**
Если токен содержит пробелы или переносы строк:
1. Скопируйте токен заново с GitHub
2. Вставьте в текстовый редактор (например, Notepad)
3. Удалите все пробелы и переносы строк
4. Скопируйте очищенный токен
5. Вставьте в настройки GitHub на сайте

### 3. Неправильный формат заголовка Authorization

**Как проверить:**
1. Откройте консоль браузера (F12)
2. Вставьте код из файла `docs/diagnose-token.js`
3. Нажмите Enter
4. Посмотрите результат теста

**Что должно быть:**
- ✅ Запрос с заголовком `Authorization: Bearer <token>` работает
- ✅ Или запрос с заголовком `Authorization: token <token>` работает

**Решение:**
Если ни один формат не работает, возможно, проблема в коде. Нужно проверить функцию `testGitHubConnection` и `writeToGitHub`.

## 🚀 Пошаговая диагностика

### Шаг 1: Запустите диагностический скрипт

1. Откройте сайт
2. Нажмите **F12** → вкладка **Console**
3. Скопируйте весь код из файла `docs/diagnose-token.js`
4. Вставьте в консоль
5. Нажмите **Enter**
6. Посмотрите результат

### Шаг 2: Проверьте токен на GitHub

1. Откройте https://github.com/settings/tokens
2. Нажмите на ваш токен
3. Проверьте:
   - ✅ Токен не истёк (действителен до 5 декабря)
   - ✅ Отмечен чекбокс `repo`
   - ✅ Токен начинается с `ghp_` или `github_pat_`

### Шаг 3: Скопируйте токен заново

1. На странице токена нажмите **"Regenerate token"** (или создайте новый)
2. Скопируйте токен
3. Вставьте в текстовый редактор (Notepad)
4. Удалите все пробелы и переносы строк
5. Скопируйте очищенный токен
6. Вставьте в настройки GitHub на сайте

### Шаг 4: Проверьте соединение

1. Нажмите **"🔍 Тест"** в настройках GitHub
2. Посмотрите результат в консоли (F12)

## 💡 Если ничего не помогло

### Попробуйте создать новый токен с нуля

1. Откройте https://github.com/settings/tokens
2. Удалите старый токен
3. Нажмите **"Generate new token (classic)"**
4. Заполните:
   - **Note**: `Rating System`
   - **Expiration**: `90 days`
   - ✅ **Select scopes**: `repo` (полный доступ)
5. Нажмите **"Generate token"**
6. Скопируйте токен (начинается с `ghp_...`)
7. Вставьте в настройки GitHub на сайте

### Проверьте код

Если проблема в коде, нужно проверить функции:
- `testGitHubConnection()` - проверка соединения
- `writeToGitHub()` - запись файла в GitHub

Возможно, используется неправильный формат заголовка Authorization.
