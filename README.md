# Система рейтинга курсантов

Веб-приложение для отслеживания успеваемости курсантов по дисциплине "Информационные технологии в юридической деятельности".

## 🚀 Возможности

- ✅ Рейтинг курсантов по группам
- ✅ Автоматический расчёт баллов по категориям
- ✅ Система оценок (3, 4, 5) с автоматическим переводом в баллы
- ✅ Дополнительные баллы (конспекты, доклады)
- ✅ Синхронизация данных между устройствами через GitHub API
- ✅ Экспорт/импорт данных в JSON
- ✅ Адаптивный дизайн для мобильных устройств

## 📊 Категории оценивания

### Основные (входят в максимум):
- **Практические работы**: оценка 3→3б, 4→7б, 5→10б (макс. 500)
- **Тестирование**: оценка 3→3б, 4→7б, 5→10б (макс. 500)

### Дополнительные (не входят в максимум):
- **Конспекты**: 2 балла за конспект лекции (макс. 500)
- **Доклады**: оценка 3→3б, 4→6б, 5→8б (макс. 500)
- **Доп. баллы**: на усмотрение преподавателя (макс. 500)

## 🔄 Синхронизация через GitHub API

### Зачем нужна синхронизация?

Без синхронизации изменения, внесённые на одном устройстве, не видны на других. GitHub API решает эту проблему, синхронизируя данные через облачный репозиторий.

### Как настроить?

1. **Создайте репозиторий на GitHub**
   - Перейдите на https://github.com/
   - Создайте новый публичный репозиторий (например, `rating-system`)
   - Добавьте файл `data.json` (скопируйте из корня этого проекта)

2. **Создайте Personal Access Token**
   - Перейдите на https://github.com/settings/tokens
   - Нажмите "Generate new token (classic)"
   - Выберите права `repo`
   - Скопируйте токен (начинается с `ghp_...`)

3. **Настройте синхронизацию в приложении**
   - Войдите как преподаватель
   - Нажмите "⚙️ GitHub"
   - Заполните поля:
     - Владелец репозитория: ваш username
     - Название репозитория: `rating-system`
     - Token: ваш токен
     - Путь к файлу: `data.json`
     - Ветка: `main`
   - Нажмите "Сохранить"

4. **Проверьте работу**
   - Внесите изменения на одном устройстве
   - Нажмите "💾 Сохранить"
   - На другом устройстве нажмите "🔄 Синхронизация"
   - Данные должны обновиться!

### Подробная инструкция

См. файл [GITHUB_SETUP.md](GITHUB_SETUP.md) или откройте [github-setup.html](docs/github-setup.html) в браузере.

## 💾 Резервное копирование

Данные автоматически сохраняются:
- В GitHub (если настроена синхронизация)
- В localStorage браузера (локально)

Для ручного резервного копирования:
1. Нажмите "💾 Экспорт" — скачается JSON файл
2. Сохраните его в надёжном месте
3. Для восстановления нажмите "📂 Загрузить" и выберите файл

## 🌐 Деплой на GitHub Pages

1. Создайте репозиторий на GitHub
2. Загрузите все файлы
3. Перейдите в Settings → Pages
4. Выберите ветку `main` и папку `/docs`
5. Нажмите "Save"
6. Сайт будет доступен по адресу: `https://username.github.io/repo-name/`

## 🔒 Безопасность

- Пароль преподавателя хранится в коде (не используйте для продакшена)
- GitHub token хранится в localStorage браузера
- Не передавайте token другим людям
- Используйте HTTPS (GitHub Pages автоматически использует HTTPS)
