# ✅ Быстрое решение конфликта версий

## 🎯 Проблема

Возникает ошибка:
```
Ошибка: Конфликт версий. Файл был изменён. Попробуйте ещё раз.
```

## 🔧 Быстрое решение (2 минуты)

### Шаг 1: Проверьте настройки GitHub

1. Откройте сайт
2. Войдите как преподаватель (пароль: `05072020`)
3. Нажмите **"⚙️ GitHub"**
4. Проверьте поле **"Путь к файлу данных"**

**Должно быть:** `data.json`

❌ Если указано что-то другое (например, `docs/data.json`) → **это причина проблемы!**

### Шаг 2: Исправьте настройки

1. Измените поле **"Путь к файлу данных"** на: `data.json`
2. Нажмите **"Сохранить"**
3. Нажмите **"🔍 Тест"** для проверки
4. Нажмите **"💾 Сохранить"** для записи данных

### Шаг 3: Готово!

Теперь данные будут записываться в правильный файл `data.json` в корне репозитория.

---

## 🔍 Если не помогло

### Проверьте в консоли браузера (F12):

```javascript
const config = JSON.parse(localStorage.getItem('github_config'));
console.log('Настройки GitHub:', config);
```

**Что должно быть:**
```javascript
{
  owner: "ваш-username",
  repo: "ваш-репозиторий",
  token: "ghp_...",
  filePath: "data.json",  // ← ВАЖНО!
  branch: "main"
}
```

### Если `filePath` другой:

1. Очистите localStorage:
```javascript
localStorage.clear();
location.reload();
```

2. Снова настройте GitHub через **"⚙️ GitHub"**
3. Убедитесь, что путь указан как `data.json`

---

## 📊 Проверка после исправления

1. Добавьте курсанта через интерфейс
2. Нажмите **"💾 Сохранить"**
3. Откройте репозиторий на GitHub
4. Найдите файл `data.json` в **корне репозитория**
5. Проверьте, что курсант там есть

---

## 💡 Почему возникла проблема?

Система записывает данные в файл, указанный в настройках GitHub (`filePath`).

**Если было указано:**
- ❌ `docs/data.json` → данные записывались в папку docs
- ❌ `rating-data.json` → данные записывались в другой файл
- ❌ Пустое значение → ошибка

**Должно быть:**
- ✅ `data.json` → данные записываются в корень репозитория
