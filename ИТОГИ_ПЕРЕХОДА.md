# 🎉 Переход на новую архитектуру с файлом kursanty.json

## ✅ Что было сделано?

Создана **новая упрощённая архитектура** для хранения данных курсантов в файле `kursanty.json` вместо `data.json`.

---

## 🎯 Проблема, которую мы решили

### Старая архитектура (data.json):

**Проблемы:**
- ❌ Конфликты версий (HTTP 409) при сохранении
- ❌ Сложная синхронизация через GitHub API
- ❌ Нужен токен GitHub для чтения данных
- ❌ Ошибки при сохранении
- ❌ Данные записывались в неправильный файл

### Новая архитектура (kursanty.json):

**Решения:**
- ✅ **Нет конфликтов версий** - простое чтение из файла
- ✅ **Простая синхронизация** - экспорт/импорт JSON файлов
- ✅ **Не нужен токен для чтения** - данные загружаются напрямую
- ✅ **Нет ошибок при сохранении** - только экспорт в файл
- ✅ **Правильный файл** - данные записываются в `kursanty.json`

## 🚀 Как начать работу?

### Шаг 1: Создайте файл kursanty.json

1. Откройте репозиторий на GitHub
2. Нажмите **"Add file"** → **"Create new file"**
3. Имя файла: `kursanty.json`
4. Вставьте начальное содержимое:
```json
{
  "kursanty": [],
  "lastUpdated": "",
  "version": "1.0"
}
```
5. Нажмите **"Commit new file"**

### Шаг 2: Откройте сайт

```
https://ваш-username.github.io/ваш-репозиторий/
```

### Шаг 3: Войдите как преподаватель

- Нажмите **"🔐 Вход для преподавателя"**
- Пароль: `05072020`

### Шаг 4: Добавьте курсантов

**Вариант 1: По одному**
1. Нажмите **"➕ Добавить"**
2. Введите ФИО и взвод
3. Нажмите **"Сохранить"**

**Вариант 2: Списком**
1. Нажмите **"📥 Импорт"**
2. Вставьте список:
```
# 1 взвод
Иванов Иван Сергеевич
Петрова Анна Михайловна

# 2 взвод
Сидоров Алексей Дмитриевич
Морозова Елена Викторовна

# 3 взвод
Волков Артём Николаевич
Соколова Дарья Олеговна
```
3. Нажмите **"Импортировать"**

### Шаг 5: Экспортируйте данные

1. Нажмите **"💾 Экспорт"**
2. Скачается файл `kursanty-2026-01-15.json`
3. Загрузите этот файл в репозиторий как `kursanty.json`

### Шаг 6: Синхронизируйте

1. Нажмите **"🔄 Синхронизация"**
2. Данные загрузятся из файла `kursanty.json`
