# ✅ Проверка загрузки данных курсантов

## 📊 Как работают данные?

### Источник данных

Все данные курсантов хранятся в файле **`data.json`** в корне репозитория на GitHub.

### Загрузка данных

При открытии сайта система автоматически:

1. **Загружает данные из файла `data.json`**
   - URL: `https://ваш-username.github.io/ваш-репозиторий/data.json`
   - Данные парсятся и отображаются в таблицах

2. **Сохраняет резервную копию в localStorage**
   - На случай, если файл `data.json` недоступен
   - Данные синхронизируются между устройствами через GitHub

3. **Отображает курсантов в интерфейсе**
   - Общий рейтинг (все курсанты)
   - Рейтинг по взводам (фильтрация по группам)

## 🎯 Как добавить курсантов по взводам?

### Способ 1: Через интерфейс (рекомендуется)

1. **Войдите как преподаватель** (пароль: `05072020`)

2. **Добавьте одного курсанта:**
   - Нажмите **"➕ Добавить"**
   - Введите ФИО курсанта
   - Введите название взвода (например: "1 взвод")
   - Нажмите **"💾 Сохранить"**

3. **Или импортируйте список:**
   - Нажмите **"📥 Импорт"**
   - Вставьте список в формате:
     ```
     # 1 взвод
     Иванов Иван Сергеевич
     Петрова Анна Михайловна
     
     # 2 взвод
     Сидоров Алексей Дмитриевич
     Морозова Елена Викторовна
     
     # 3 взвод
     Волков Артём Николаевич
     Соколова Дарья Олеговна
     ```
   - Нажмите **"Импортировать"**
   - Нажмите **"💾 Сохранить"**

### Способ 2: Редактирование файла data.json

1. Откройте репозиторий на GitHub
2. Найдите файл `data.json`
3. Нажмите иконку карандаша для редактирования
4. Добавьте новых курсантов в массив `students`
5. Сохраните изменения (Commit)

1. **Данные загружаются из файла `data.json`**
