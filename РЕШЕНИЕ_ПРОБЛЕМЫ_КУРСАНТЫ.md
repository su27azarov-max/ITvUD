## 🔑 Решение проблемы 2: Ошибка 401 - Неверный токен

### Шаг 1: Создайте новый токен GitHub

1. Откройте https://github.com/settings/tokens
2. Нажмите **"Generate new token"** → **"Generate new token (classic)"**
3. Заполните форму:
   - **Note**: `Rating System` (любое описание)
   - **Expiration**: `90 days` (или `No expiration`)
   - **Select scopes**: ✅ отметьте **`repo`** (полный доступ)
4. Прокрутите вниз
5. Нажмите **"Generate token"**
6. **СКОПИРУЙТЕ ТОКЕН** (начинается с `ghp_...`)

⚠️ **ВАЖНО:** Вы не сможете увидеть токен снова! Сохраните его в надёжном месте.

### Шаг 2: Обновите токен в настройках

1. Откройте сайт
2. Войдите как преподаватель (пароль: `05072020`)
3. Нажмите **"⚙️ GitHub"**
4. В поле **"Personal Access Token"** вставьте новый токен
5. Нажмите **"Сохранить"**
6. Нажмите **"🔍 Тест"** для проверки

### Шаг 3: Проверьте соединение

В консоли браузера (F12) должно быть:

## 💡 Что изменилось в коде?

### Функция `loadDataFromJson()`

**Было:**
```javascript
if (data.kursanty && Array.isArray(data.kursanty)) {
    students = data.kursanty.map(s => ensureStudent(s));
} else {
    console.warn('⚠️ Файл kursanty.json не содержит массив kursanty');
}
```

**Стало:**
```javascript
// Поддержка обоих форматов: kursanty (новый) и students (старый)
let kursantyList = null;
if (data.kursanty && Array.isArray(data.kursanty)) {
    kursantyList = data.kursanty;
    console.log('✅ Формат: новый (kursanty)');
} else if (data.students && Array.isArray(data.students)) {
    kursantyList = data.students;
    console.log('✅ Формат: старый (students) - конвертируем');
}

if (kursantyList) {
    students = kursantyList.map(s => ensureStudent(s));
}
```

**Результат:** Теперь код поддерживает оба формата данных!
