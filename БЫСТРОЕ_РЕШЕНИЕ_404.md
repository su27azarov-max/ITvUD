# ⚡ Быстрое решение: Ошибка 404 при записи в docs/kursanty.json

## 🎯 Проблема

```
PUT https://api.github.com/repos/.../contents/docs/kursanty.json 404 (Not Found)
```

Файл `docs/kursanty.json` не существует в репозитории.

## ✅ Решение за 3 шага

### Шаг 1: Обновите код на GitHub

1. Откройте: https://github.com/su27azarov-max/ITvUD/blob/main/docs/index.html
2. Нажмите на иконку карандаша ✏️
3. **Замените весь код** на содержимое файла `docs/index.html` из этого проекта
4. Нажмите **Commit changes**
5. Подождите 1-2 минуты

### Шаг 2: Проверьте права токена

Убедитесь, что Fine-grained token имеет:
- ✅ **Contents**: Read and write
- ✅ **Metadata**: Read-only

Если нет - создайте новый токен с этими правами.

### Шаг 3: Проверьте работу

1. Откройте сайт
2. Войдите как преподаватель
3. Выставьте оценку курсанту
4. В консоли (F12) должно быть:

```
📝 Файл не существует, будет создан новый: docs/kursanty.json
✅ Данные сохранены в GitHub
📁 Файл: docs/kursanty.json
```

5. Проверьте репозиторий - файл `docs/kursanty.json` должен появиться

## 🔧 Что изменилось в коде

**Было**: Код пытался обновить несуществующий файл → ошибка 404

**Стало**: Код проверяет существование файла и создаёт его, если нужно

```javascript
// Проверяем существование файла
const getResponse = await fetch(url, {...});

if (getResponse.ok) {
    // Файл существует - обновляем с SHA
    sha = existingData.sha;
    console.log('✅ Файл существует');
} else if (getResponse.status === 404) {
    // Файл не существует - создаём новый
    console.log('📝 Файл не существует, будет создан новый');
    sha = null; // Без SHA создаётся новый файл
}

// Отправляем данные
const requestBody = {
    message: fileExists ? 'Обновление...' : 'Создание...',
    content: content,
    branch: GITHUB_CONFIG.branch
};

if (sha) {
    requestBody.sha = sha; // SHA нужен только для обновления
}
```
