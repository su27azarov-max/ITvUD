🔧 Переход на JSONBin.io — Решение проблемы с GitHub API

⚠️ Почему GitHub API не работает?
Fine-grained token требует точной настройки прав "Contents: Read and write". Даже при правильной настройке часто возникают ошибки 401/404. JSONBin.io решает ВСЕ эти проблемы.
✅ Преимущества JSONBin.io:
  • Бесплатно (10,000 запросов/месяц)
  • Не требует настройки прав
  • Нет проблем с CORS
  • Простой REST API
  • Данные доступны по URL
  • Работает с любого устройства

🚀 Пошаговая инструкция

1 Регистрация на JSONBin.io
  1. Перейдите на https://jsonbin.io
  2. Нажмите "Sign Up"
  3. Зарегистрируйтесь через Google или Email
  4. После регистрации вы попадёте в Dashboard
2 Получите API Key
  1. В Dashboard найдите раздел "API Key"
  2. Скопируйте ваш API Key (начинается с $2a$10$...)
  3. Сохраните его в надёжном месте
⚠️ Важно: API Key — это ваш секретный ключ. Не передавайте его другим!
3 Создайте Bin (хранилище данных)
  1. В Dashboard нажмите "Create Bin"
  2. Вставьте начальное содержимое:
{
  "kursanty": [],
  "lastUpdated": "",
  "version": "1.0"
}
  1. Нажмите "Create Bin"
  2. Скопируйте Bin ID (например: 65a1b2c3d4e5f6a7b8c9d0e1)
4 Настройте сайт
  1. Откройте сайт
  2. Войдите как преподаватель (пароль: 05072020)
  3. Нажмите "⚙️ JSONBin" (новая кнопка вместо "⚙️ GitHub")
  4. Вставьте:
    • API Key: ваш ключ из шага 2
    • Bin ID: ваш ID из шага 3
  5. Нажмите "Сохранить"
  6. Нажмите "🔍 Тест" для проверки
5 Проверьте работу
  1. Выставьте оценку курсанту
  2. Через 2 секунды должно появиться: "✅ Данные сохранены!"
  3. Откройте сайт на другом устройстве
  4. Нажмите "🔄 Синхронизация"
  5. Данные должны появиться!

🔒 Безопасность

  • ✅ API Key хранится только в вашем браузере (localStorage)
  • ✅ Bin ID — это публичный идентификатор, но без API Key его нельзя изменить
  • ✅ HTTPS шифрование для всех запросов
  • ✅ Вы можете удалить Bin в любой момент

💾 Резервное копирование

Даже с JSONBin.io рекомендуется делать резервные копии:

  1. Нажмите "💾 Экспорт" — скачается JSON файл
  2. Сохраните файл в надёжном месте
  3. При необходимости можно импортировать данные обратно
