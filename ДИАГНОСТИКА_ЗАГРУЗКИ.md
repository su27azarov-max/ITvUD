# 🔧 Диагностика проблемы с загрузкой данных

## 🎯 Проблема

Курсанты введены в интерфейс, но при обновлении страницы показываются пустые списки. Сообщение: "Преподаватель еще ничего не загрузил".

## 🔍 Причина проблемы

Данные курсантов находятся **только в localStorage браузера**, но **не в файле `kursanty.json`** в репозитории.

### Как это работает:

```
1. Преподаватель вводит курсантов в интерфейсе
   ↓
2. Данные сохраняются в localStorage браузера ✅
   ↓
3. Данные НЕ экспортируются в файл kursanty.json ❌
   ↓
4. При обновлении страницы данные загружаются из файла kursanty.json
   ↓
5. Файл пустой → показывается "Преподаватель еще ничего не загрузил"
```

## ✅ Решение

### Шаг 1: Проверьте, есть ли данные в localStorage

1. Откройте сайт
2. Нажмите **F12** (откроется консоль разработчика)
3. Перейдите на вкладку **Console**
4. Введите команду:

```javascript
const data = localStorage.getItem('rating_students');
console.log('Данные в localStorage:', data ? JSON.parse(data) : 'Пусто');
```

**Если данные есть:**
- Вы увидите массив курсантов
- Переходите к Шагу 2

**Если данных нет:**
- Курсанты не были введены в этом браузере
- Введите курсантов заново

### Шаг 2: Экспортируйте данные из localStorage в файл

1. В консоли браузера (F12) введите:

```javascript
// Получаем данные из localStorage
const students = JSON.parse(localStorage.getItem('rating_students') || '[]');
const categories = JSON.parse(localStorage.getItem('rating_categories') || '[]');

// Создаём объект для экспорта
const exportData = {
    kursanty: students,
    lastUpdated: new Date().toISOString(),
    version: "1.0"
};

// Создаём JSON строку
const jsonString = JSON.stringify(exportData, null, 2);

// Создаём Blob и скачиваем файл
const blob = new Blob([jsonString], { type: 'application/json' });
const url = URL.createObjectURL(blob);
const a = document.createElement('a');
a.href = url;
a.download = 'kursanty.json';
document.body.appendChild(a);
a.click();
document.body.removeChild(a);
URL.revokeObjectURL(url);

console.log('✅ Файл kursanty.json скачан!');
console.log('Количество курсантов:', students.length);
```

2. Файл `kursanty.json` будет скачан на ваш компьютер

### Шаг 3: Загрузите файл в репозиторий

1. Откройте репозиторий на GitHub
2. Нажмите **"Add file"** → **"Upload files"**
3. Перетащите скачанный файл `kursanty.json`
4. Или нажмите **"choose your files"** и выберите файл
5. Внизу страницы нажмите **"Commit changes"**
6. Дождитесь 1-2 минуты для обновления GitHub Pages

### Шаг 4: Проверьте результат

1. Откройте сайт заново
2. Нажмите **F12** → вкладка **Console**
3. Вы должны увидеть:

```
📥 Загрузка данных из kursanty.json...
📡 URL для загрузки: https://ваш-username.github.io/ваш-репозиторий/kursanty.json
✅ Загружено курсантов: N
✅ Данные загружены из kursanty.json
```

4. Курсанты должны появиться в интерфейсе

## 🐛 Если данные не загружаются

### Проверка 1: URL файла

1. Откройте сайт
2. Нажмите **F12** → вкладка **Console**
3. Введите:

```javascript
const repoUrl = window.location.origin + window.location.pathname.replace(/\/[^\/]*$/, '');
const dataUrl = repoUrl + '/kursanty.json';
console.log('URL для загрузки:', dataUrl);
```

4. Скопируйте URL и откройте его в новой вкладке
5. Вы должны увидеть содержимое файла `kursanty.json`

**Если файл не открывается:**
- Файл не загружен в репозиторий
- Или GitHub Pages ещё не обновился (подождите 1-2 минуты)

### Проверка 2: CORS проблемы

1. В консоли браузера (F12) проверьте ошибки
2. Если видите ошибку CORS:

```
Access to fetch at '...' from origin '...' has been blocked by CORS policy
```

**Решение:**
- Убедитесь, что файл `kursanty.json` находится в корне репозитория
- Проверьте, что GitHub Pages включён
- Подождите 1-2 минуты после загрузки файла

### Проверка 3: Кэш браузера

1. Нажмите **Ctrl+Shift+Delete**
2. Выберите "Кэшированные изображения и файлы"
3. Нажмите "Удалить данные"
4. Обновите страницу (**Ctrl+F5**)
