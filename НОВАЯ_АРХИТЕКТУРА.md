# 📁 Новая архитектура: Работа с файлом data.json

## 🎯 Что изменилось?

Вместо сложной синхронизации через GitHub API, теперь система работает напрямую с файлом `data.json`:

### Старая архитектура:
```
Браузер → GitHub API → data.json (сложная синхронизация)
```

### Новая архитектура:
```
Браузер → data.json (прямое чтение)
Браузер → GitHub API → data.json (запись через API)
```

## 🔄 Как это работает?

### Чтение данных (загрузка страницы)

1. При открытии страницы система загружает данные из файла `data.json`
2. URL для загрузки: `https://ваш-username.github.io/ваш-репозиторий/data.json`
3. Данные парсятся и отображаются в таблице
4. Если файл не найден - используются данные из localStorage

**Преимущества:**
- ✅ Простой HTTP запрос (не нужен GitHub API)
- ✅ Нет проблем с CORS
- ✅ Нет проблем с токенами
- ✅ Быстрая загрузка
- ✅ Надёжная работа

### Запись данных (сохранение)

1. При нажатии "💾 Сохранить" данные отправляются в GitHub через API
2. GitHub обновляет файл `data.json` в репозитории
3. GitHub Pages автоматически обновляет сайт
4. Через 1-2 минуты изменения видны всем пользователям

**Преимущества:**
- ✅ Данные хранятся в файле репозитория
- ✅ История изменений в Git
- ✅ Резервное копирование
- ✅ Возможность редактирования файла вручную

## 🚀 Как пользоваться?

### Первый запуск

1. Откройте сайт
2. Войдите как преподаватель (пароль: `05072020`)
3. Нажмите **"⚙️ GitHub"** и настройте синхронизацию:
   - Владелец: ваш username на GitHub
   - Репозиторий: название репозитория
   - Token: ваш Personal Access Token
   - Путь: `data.json`
   - Ветка: `main`
4. Нажмите **"🔍 Тест"** для проверки соединения
5. Нажмите **"💾 Сохранить"** для создания файла data.json

### Ежедневная работа

1. **Загрузка данных:**
   - Данные автоматически загружаются из `data.json` при открытии страницы
   - Или нажмите **"🔄 Синхронизация"** для принудительной загрузки

2. **Внесение изменений:**
   - Добавьте курсантов
   - Начислите баллы
   - Измените веса категорий

3. **Сохранение:**
   - Нажмите **"💾 Сохранить"**
   - Данные сохранятся в `data.json` через GitHub API
   - Через 1-2 минуты изменения будут видны всем

### Проверка данных

1. Откройте репозиторий на GitHub
2. Найдите файл `data.json`
3. Посмотрите содержимое - там все данные курсантов
4. Можно редактировать файл вручную через GitHub

## 🔧 Решение проблем

### Проблема: "failed to fetch" при синхронизации

**Причина:** Браузер не может загрузить файл `data.json`

**Решение:**
1. Проверьте, что файл `data.json` существует в репозитории
2. Проверьте, что GitHub Pages включён
3. Подождите 1-2 минуты после публикации изменений
4. Очистите кэш браузера (Ctrl+Shift+Delete)

### Проблема: Данные не обновляются на другом устройстве

**Причина:** GitHub Pages кэширует файлы

**Решение:**
1. Нажмите **"🔄 Синхронизация"** на другом устройстве
2. Или обновите страницу с очисткой кэша (Ctrl+F5)
3. Подождите 1-2 минуты после сохранения

### Проблема: Ошибка при сохранении в GitHub

**Причина:** Проблемы с GitHub API

**Решение:**
1. Проверьте настройки GitHub (кнопка "⚙️ GitHub")
2. Убедитесь, что токен действителен
3. Проверьте права токена (должен быть `repo`)
4. Проверьте имя владельца и репозитория

## 🎓 Как это работает технически?

### Чтение данных

```javascript
async function loadDataFromJson() {
    // Получаем URL текущего репозитория
    const repoUrl = window.location.origin + window.location.pathname.replace(/\/[^\/]*$/, '');
    const dataUrl = repoUrl + '/data.json';
    
    // Загружаем файл напрямую (простой HTTP запрос)
    const response = await fetch(dataUrl, {
        cache: 'no-store'
    });
    
    if (response.ok) {
        const data = await response.json();
        students = data.students;
        categories = data.categories;
        renderAll();
    }
}
```

### Запись данных

```javascript
async function writeToGitHub() {
    const url = `https://api.github.com/repos/${owner}/${repo}/contents/data.json`;
    
    // Получаем SHA файла
    const getResponse = await fetch(url, {
        headers: { 'Authorization': `Bearer ${token}` }
    });
    const sha = (await getResponse.json()).sha;
    
    // Кодируем данные в base64
    const content = btoa(JSON.stringify(data));
    
    // Отправляем запрос на обновление
    await fetch(url, {
        method: 'PUT',
        headers: { 'Authorization': `Bearer ${token}` },
        body: JSON.stringify({
            message: 'Обновление данных',
            content: content,
            sha: sha,
            branch: 'main'
        })
    });
}
```
