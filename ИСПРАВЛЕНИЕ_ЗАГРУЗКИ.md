# 🔧 Диагностика и исправление проблемы с загрузкой данных

## 🎯 Проблема

Курсанты загружаются только в локальном режиме (localStorage), но не в онлайн режиме (из файла `kursanty.json`).

## 🔍 Причина

Проблема в формировании URL для загрузки файла `kursanty.json`.

## ✅ Решение

### Шаг 1: Обновите код сайта

Код в `docs/index.html` уже исправлен. Теперь нужно загрузить обновлённый файл в репозиторий.

### Шаг 2: Загрузите обновлённый index.html

1. Откройте репозиторий на GitHub
2. Перейдите в папку `docs/`
3. Нажмите на файл `index.html`
4. Нажмите иконку карандаша (Edit this file)
5. Скопируйте весь код из локального файла `docs/index.html`
6. Вставьте в редактор на GitHub
7. Нажмите **"Commit changes"**
8. Подождите **1-2 минуты** для обновления GitHub Pages

### Шаг 3: Проверьте загрузку данных

1. Откройте сайт
2. Нажмите **F12** (консоль разработчика)
3. Перейдите на вкладку **Console**
4. Вы должны увидеть:

```
📥 Загрузка данных из kursanty.json...
📡 URL для загрузки: https://ваш-username.github.io/ваш-репозиторий/kursanty.json
🔍 Текущий URL: https://ваш-username.github.io/ваш-репозиторий/
📥 Статус ответа: 200 OK
📦 Получены данные: {kursanty: Array(N), lastUpdated: "...", version: "1.0"}
✅ Загружено курсантов: N
✅ Данные загружены из kursanty.json (N курсантов)
```

### Шаг 4: Если данные не загружаются

Используйте диагностический скрипт:

1. Откройте сайт
2. Нажмите **F12** → вкладка **Console**
3. Скопируйте весь код из файла `docs/diagnose-load.js`
4. Вставьте в консоль
5. Нажмите **Enter**
6. Следуйте инструкциям в выводе

## 🔍 Диагностика вручную

### Проверка 1: URL файла

Откройте в браузере:
```
https://ваш-username.github.io/ваш-репозиторий/kursanty.json
```

**Должен открыться файл с данными курсантов**

Если файл не открывается:
- Файл не загружен в репозиторий
- Или GitHub Pages ещё не обновился
- Или неправильный URL

### Проверка 2: Консоль браузера

Откройте сайт и нажмите **F12** → вкладка **Console**

**Правильный вывод:**
```
📥 Загрузка данных из kursanty.json...
📡 URL для загрузки: https://username.github.io/repo-name/kursanty.json
📥 Статус ответа: 200 OK
✅ Загружено курсантов: 15
✅ Данные загружены из kursanty.json
```

**Неправильный вывод:**
```
📥 Загрузка данных из kursanty.json...
📡 URL для загрузки: https://username.github.io/repo-name/docs/kursanty.json
⚠️ Не удалось загрузить kursanty.json (статус: 404), используем localStorage
```

Если URL содержит `/docs/kursanty.json` - это ошибка! Файл должен быть в корне репозитория.

### Проверка 3: Содержимое файла

Откройте файл `kursanty.json` в репозитории и убедитесь, что он содержит:

```json
{
  "kursanty": [
    {
      "id": 1,
      "fullName": "Иванов Иван Сергеевич",
      "group": "1 взвод",
      ...
    }
  ],
  "lastUpdated": "2026-01-15T10:00:00.000Z",
  "version": "1.0"
}
```

**Важно:** Поле должно называться `kursanty`, а не `students`!

## 🚀 Быстрое решение

Если ничего не помогает, выполните эти шаги:

### 1. Очистите localStorage

В консоли браузера (F12) введите:
```javascript
localStorage.clear();
location.reload();
```

### 2. Проверьте файл kursanty.json

Убедитесь, что файл:
- ✅ Находится в корне репозитория (не в папке `docs/`)
- ✅ Называется именно `kursanty.json` (не `data.json`)
- ✅ Содержит поле `kursanty` (не `students`)
- ✅ Является валидным JSON

### 3. Загрузите обновлённый index.html

Скопируйте код из `docs/index.html` и загрузите в репозиторий.

### 4. Подождите 2-3 минуты

GitHub Pages нужно время для обновления.

### 5. Обновите страницу с очисткой кэша

Нажмите **Ctrl+Shift+R** или **Ctrl+F5**

## 🐛 Типичные ошибки

### Ошибка 1: 404 Not Found

**Причина:** Файл `kursanty.json` не найден

**Решение:**
- Проверьте, что файл загружен в репозиторий
- Проверьте, что файл находится в корне репозитория
- Проверьте правильность URL

### Ошибка 2: CORS policy

**Причина:** Браузер блокирует запрос из-за политики CORS

**Решение:**
- Убедитесь, что GitHub Pages включён
- Проверьте, что файл находится в публичном репозитории
- Подождите 2-3 минуты после загрузки файла

### Ошибка 3: Unexpected token

**Причина:** Файл `kursanty.json` содержит синтаксическую ошибку

**Решение:**
- Откройте файл в текстовом редакторе
- Проверьте синтаксис JSON
- Используйте валидатор JSON (например, jsonlint.com)

### Ошибка 4: Данные не отображаются

**Причина:** Данные загружены, но не отображаются

**Решение:**
- Проверьте консоль браузера на ошибки
- Убедитесь, что функция `renderAll()` вызывается
- Проверьте, что массив `students` не пустой
