🔧 Настройка синхронизации GitHub

Пошаговая инструкция по исправлению проблемы с синхронизацией

⚠️ Важно: Следуйте инструкциям шаг за шагом. Не пропускайте шаги!

1 Создайте репозиторий на GitHub

Если у вас ещё нет репозитория:

  1. Перейдите на github.com/new
  2. Заполните форму:
    • Repository name: rating-system (или любое другое)
    • Description: Система рейтинга курсантов
    • Public: ✅ выберите Public
    • Add a README: ✅ отметьте
  3. Нажмите "Create repository"
📸 Скриншот создания репозитория

2 Создайте файл data.json

В созданном репозитории:

  1. Нажмите "Add file" → "Create new file"
  2. В поле имени файла введите: data.json
  3. Вставьте содержимое:
    { "students": [], "categories": [], "lastUpdated": "" }
  4. Прокрутите вниз
  5. Введите сообщение: Начальные данные
  6. Нажмите "Commit new file"

3 Создайте Personal Access Token

  1. Перейдите на github.com/settings/tokens
  2. Нажмите "Generate new token" → "Generate new token (classic)"
  3. Заполните форму:
    • Note: Rating System
    • Expiration: 90 days
    • Select scopes: ✅ отметьте repo
  4. Прокрутите вниз и нажмите "Generate token"
  5. СКОПИРУЙТЕ ТОКЕН (начинается с ghp_...)
    ⚠️ Важно: Вы не сможете увидеть токен снова! Сохраните его в надёжном месте.

4 Настройте синхронизацию на сайте

  1. Откройте основной сайт
  2. Войдите как преподаватель (пароль: 05072020)
  3. Нажмите кнопку "⚙️ GitHub" в панели инструментов
  4. Заполните поля:
    • Владелец репозитория: ваш username на GitHub
    • Название репозитория: rating-system
    • Personal Access Token: вставьте скопированный токен
    • Путь к файлу данных: data.json
    • Ветка: main
  5. Нажмите "Сохранить"
📸 Скриншот настроек GitHub

5 Протестируйте соединение

  1. В окне настроек GitHub нажмите "🔍 Тест"
  2. Дождитесь результата
  3. Если всё хорошо - увидите сообщение "✅ Соединение с GitHub работает!"
✅ Успех: Если тест прошёл успешно, переходите к шагу 6.
❌ Ошибка: Если есть ошибки, читайте раздел "Частые проблемы" ниже.

6 Проверьте синхронизацию

  1. Внесите любые изменения (например, добавьте курсанта)
  2. Нажмите "💾 Сохранить"
  3. Дождитесь сообщения "✅ Изменения сохранены в GitHub!"
  4. Откройте репозиторий на GitHub
  5. Проверьте файл data.json - он должен обновиться

7 Проверьте на другом устройстве

  1. Откройте сайт на другом устройстве
  2. Нажмите "🔄 Синхронизация"
  3. Или обновите страницу (F5)
  4. Изменения должны появиться!
🎉 Поздравляем! Если изменения появились на другом устройстве - синхронизация работает!
