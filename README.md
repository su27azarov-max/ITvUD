## 🎯 О системе

Веб-приложение для отслеживания успеваемости курсантов по дисциплине "Информационные технологии в юридической деятельности".

## 🚀 Быстрый старт

### 1. Настройка GitHub (один раз)

1. Откройте сайт: `https://ваш-username.github.io/ваш-репозиторий/`
2. Войдите как преподаватель (пароль: `05072020`)
3. Нажмите **"⚙️ GitHub"** и заполните настройки:
   - **Владелец**: ваш username на GitHub
   - **Репозиторий**: название репозитория
   - **Token**: ваш Personal Access Token (начинается с `ghp_...`)
   - **Путь**: `data.json`
   - **Ветка**: `main`
4. Нажмите **"🔍 Тест"** для проверки соединения
5. Нажмите **"💾 Сохранить"** для создания файла `data.json`

### 2. Начало работы

1. **Добавьте курсантов**
   - Нажмите **"➕ Добавить"** или **"📥 Импорт"**
   - Введите ФИО и группу

2. **Начислите баллы**
   - Нажмите **"✏️ Баллы"** рядом с именем курсанта
   - Выберите категорию и введите оценки

3. **Сохраните изменения**
   - Нажмите **"💾 Сохранить"**
   - Данные сохранятся в `data.json` через GitHub

4. **Синхронизируйте на другом устройстве**
   - Откройте сайт на другом устройстве
   - Нажмите **"🔄 Синхронизация"**
   - Данные загрузятся из `data.json`

## 🏆 Шкала оценок

Оценка рассчитывается как процент от максимума основных категорий:

| Процент | Оценка |
|---------|--------|
| ≥90% | Отлично (5) |
| 75-89% | Хорошо (4) |
| 60-74% | Удовлетворительно (3) |
| <60% | Неудовлетворительно (2) |

**Пример:**
- Максимум основных категорий: 1000 баллов
- Студент набрал: 850 баллов
- Процент: 85% → **Хорошо (4)**

## 🔧 Решение проблем

### Проблема: "failed to fetch" при синхронизации

**Решение:** Эта проблема больше не возникает! Система теперь загружает данные напрямую из файла `data.json`, а не через GitHub API.

### Проблема: Данные не загружаются

**Решение:**
1. Проверьте, что файл `data.json` существует в репозитории
2. Проверьте, что GitHub Pages включён
3. Подождите 1-2 минуты после публикации
4. Нажмите **"🔄 Синхронизация"**

### Проблема: Ошибка при сохранении

**Решение:**
1. Проверьте настройки GitHub (кнопка "⚙️ GitHub")
2. Убедитесь, что токен действителен
3. Проверьте права токена (должен быть `repo`)
4. Нажмите **"🔍 Тест"** для проверки соединения

### Проблема: Изменения не видны на другом устройстве

**Решение:**
1. Подождите 1-2 минуты после сохранения
2. Нажмите **"🔄 Синхронизация"** на другом устройстве
3. Или обновите страницу с очисткой кэша (Ctrl+F5)
