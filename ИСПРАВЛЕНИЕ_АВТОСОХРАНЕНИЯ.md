# 🔧 Исправление проблемы с автосохранением в GitHub

## 🎯 Проблема

Оценки сохраняются только локально (в localStorage), но не записываются в файл `docs/kursanty.json` на GitHub.

## 🔍 Причина

В функции `writeToGitHub()` формировался объект данных с неправильной структурой:

**Было (неправильно):**
```javascript
const data = {
    students: students,      // ❌ Неправильное имя поля
    categories: categories,  // ❌ Это поле не нужно
    lastUpdated: new Date().toISOString()
};
```

**Стало (правильно):**
```javascript
const data = {
    kursanty: students,      // ✅ Правильное имя поля
    lastUpdated: new Date().toISOString(),
    version: "1.0"
};
```

## ✅ Решение

### Шаг 1: Загрузите обновлённый код в репозиторий

1. Откройте репозиторий на GitHub
2. Перейдите в папку `docs/`
3. Откройте файл `index.html`
4. Нажмите иконку карандаша ✏️
5. Замените весь код на код из файла `docs/index.html` этого проекта
6. Нажмите **"Commit changes"**

### Шаг 2: Проверьте настройки GitHub

1. Откройте сайт
2. Войдите как преподаватель (пароль: `05072020`)
3. Нажмите **"⚙️ GitHub"**
4. Убедитесь, что поле **"Путь к файлу данных"** содержит: `docs/kursanty.json`
5. Если нет - исправьте и нажмите **"Сохранить"**

### Шаг 3: Проверьте автосохранение

1. Откройте сайт
2. Войдите как преподаватель
3. Выставьте оценку курсанту
4. Через 2 секунды должно появиться: **"✅ Данные автоматически сохранены в GitHub!"**
5. Откройте репозиторий на GitHub
6. Проверьте файл `docs/kursanty.json` - данные должны обновиться

## 🐛 Если проблема не решена

### Проблема 1: Автосохранение не работает

**Причина:** GitHub не настроен

**Решение:**
1. Нажмите **"⚙️ GitHub"**
2. Заполните все поля:
   - **Владелец**: ваш username на GitHub
   - **Репозиторий**: название репозитория
   - **Token**: ваш Personal Access Token (начинается с `ghp_...`)
   - **Путь**: `docs/kursanty.json`
   - **Ветка**: `main`
3. Нажмите **"Сохранить"**
4. Нажмите **"🔍 Тест"** для проверки

### Проблема 2: Ошибка при сохранении

**Причина:** Неправильный токен или права

**Решение:**
1. Проверьте токен на https://github.com/settings/tokens
2. Убедитесь, что токен имеет права `repo`
3. Создайте новый токен если нужно
4. Вставьте новый токен в настройки GitHub

### Проблема 3: Данные не обновляются на GitHub

**Причина:** GitHub Pages кэширует файлы

**Решение:**
1. Подождите 2-3 минуты после сохранения
2. Нажмите **Ctrl+Shift+R** для жёсткого обновления
3. Очистите кэш браузера (Ctrl+Shift+Delete)

### Проблема 4: Неправильный формат данных

**Причина:** Старая версия кода

**Решение:**
1. Убедитесь, что загрузили последнюю версию `docs/index.html`
2. Проверьте, что в коде есть строка: `kursanty: students`
3. Если нет - загрузите обновлённый код
