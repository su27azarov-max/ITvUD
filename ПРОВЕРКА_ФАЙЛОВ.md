# 🔍 Проверка файлов для синхронизации GitHub

## ✅ Необходимые файлы

Для работы синхронизации GitHub должны быть следующие файлы:

### В корне репозитория:
- ✅ `data.json` - файл с данными (создаётся автоматически при первом сохранении)
- ✅ `.nojekyll` - отключает обработку Jekyll (ВАЖНО!)
- ✅ `README.md` - описание проекта

### В папке `docs/`:
- ✅ `.nojekyll` - отключает обработку Jekyll для GitHub Pages
- ✅ `index.html` - основной файл приложения
- ✅ `check-sync.html` - страница диагностики
- ✅ `setup-guide.html` - пошаговая инструкция
- ✅ `diagnostics.html` - расширенная диагностика
- ✅ `test.html` - тестовая страница
- ✅ `test-sync.js` - скрипт тестирования
- ✅ `github-setup.html` - инструкция по настройке GitHub
- ✅ `firebase-setup.html` - инструкция по настройке Firebase

## 🐛 Найденные и исправленные проблемы

### Проблема 1: Отсутствовал файл `.nojekyll` в папке `docs/`
**Статус:** ✅ ИСПРАВЛЕНО

**Описание:** GitHub Pages по умолчанию использует Jekyll для обработки файлов. Без файла `.nojekyll` он может игнорировать некоторые файлы или обрабатывать их неправильно.

**Решение:** Создан файл `docs/.nojekyll`

## 📋 Чек-лист проверки файлов

### 1. Проверьте структуру репозитория на GitHub

Откройте ваш репозиторий на GitHub и убедитесь, что есть:

```
ваш-репозиторий/
├── .nojekyll                    ✅ ДОЛЖЕН БЫТЬ
├── data.json                    ✅ ДОЛЖЕН БЫТЬ (создаётся автоматически)
├── README.md                    ✅ ДОЛЖЕН БЫТЬ
├── docs/
│   ├── .nojekyll                ✅ ДОЛЖЕН БЫТЬ
│   ├── index.html               ✅ ДОЛЖЕН БЫТЬ
│   ├── check-sync.html          ✅ ДОЛЖЕН БЫТЬ
│   ├── setup-guide.html         ✅ ДОЛЖЕН БЫТЬ
│   ├── diagnostics.html         ✅ ДОЛЖЕН БЫТЬ
│   ├── test.html                ✅ ДОЛЖЕН БЫТЬ
│   ├── test-sync.js             ✅ ДОЛЖЕН БЫТЬ
│   ├── github-setup.html        ✅ ДОЛЖЕН БЫТЬ
│   └── firebase-setup.html      ✅ ДОЛЖЕН БЫТЬ
└── src/                         (исходный код React)
    └── ...
```

### 2. Проверьте настройки GitHub Pages

1. Откройте репозиторий на GitHub
2. Перейдите в **Settings** → **Pages**
3. Убедитесь, что настроено:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` (или `master`)
   - **Folder**: `/docs`

### 3. Проверьте файл data.json

Файл `data.json` должен быть в корне репозитория и содержать:

```json
{
  "students": [],
  "categories": [],
  "lastUpdated": ""
}
```

**Если файла нет:**
1. Создайте его вручную (Add file → Create new file)
2. Имя: `data.json`
3. Вставьте содержимое выше
4. Нажмите "Commit new file"

**Или:**
1. Откройте сайт
2. Войдите как преподаватель
3. Внесите любые изменения
4. Нажмите "💾 Сохранить"
5. Файл создастся автоматически

### 4. Проверьте файл .nojekyll

Файл `.nojekyll` должен быть:
- В корне репозитория (пустой файл)
- В папке `docs/` (пустой файл)

**Если файлов нет:**
1. Создайте их вручную (Add file → Create new file)
2. Имя: `.nojekyll`
3. Оставьте содержимое пустым
4. Нажмите "Commit new file"

## 🔧 Проверка синхронизации

### Шаг 1: Откройте консоль браузера

1. Откройте сайт
2. Нажмите **F12** (или Ctrl+Shift+I)
3. Перейдите на вкладку **Console**

### Шаг 2: Проверьте настройки GitHub

Введите в консоли:
```javascript
const config = JSON.parse(localStorage.getItem('github_config'));
console.log('Настройки GitHub:', config);
```

**Что должно быть:**
- ✅ `owner` - ваш username на GitHub
- ✅ `repo` - название репозитория
- ✅ `token` - начинается с `ghp_` или `github_pat_`
- ✅ `filePath` - `data.json`
- ✅ `branch` - `main`

### Шаг 3: Проверьте соединение

Введите в консоли:
```javascript
async function testConnection() {
    const config = JSON.parse(localStorage.getItem('github_config'));
    if (!config || !config.token) {
        console.log('❌ GitHub не настроен');
        return;
    }
    
    try {
        const url = `https://api.github.com/repos/${config.owner}/${config.repo}`;
        const response = await fetch(url, {
            headers: {
                'Authorization': `Bearer ${config.token}`,
                'Accept': 'application/vnd.github.v3+json'
            }
        });
        
        if (response.ok) {
            const data = await response.json();
            console.log('✅ Соединение работает!');
            console.log('Репозиторий:', data.full_name);
            console.log('Приватность:', data.private ? 'приватный' : 'публичный');
        } else {
            console.log('❌ Ошибка:', response.status, response.statusText);
        }
    } catch (error) {
        console.log('❌ Ошибка:', error.message);
    }
}

testConnection();
```


### Шаг 5: Тест записи

Введите в консоли:
```javascript
async function testWrite() {
    const config = JSON.parse(localStorage.getItem('github_config'));
    if (!config || !config.token) {
        console.log('❌ GitHub не настроен');
        return;
    }
    
    try {
        const url = `https://api.github.com/repos/${config.owner}/${config.repo}/contents/${config.filePath || 'data.json'}`;
        
        // Получаем SHA файла
        let sha = null;
        const getResponse = await fetch(url, {
            headers: {
                'Authorization': `Bearer ${config.token}`,
                'Accept': 'application/vnd.github.v3+json'
            }
        });
        
        if (getResponse.ok) {
            const data = await getResponse.json();
            sha = data.sha;
        }
        
        // Создаём тестовые данные
        const testData = {
            students: [{
                id: 999,
                fullName: 'ТЕСТ',
                group: 'ТЕСТ',
                notes: 0,
                practice: 0,
                reports: 0,
                bonus: 0,
                testing: 0
            }],
            categories: [],
            lastUpdated: new Date().toISOString()
        };
        
        const content = btoa(JSON.stringify(testData));
        const body = {
            message: 'Тест синхронизации',
            content: content,
            branch: config.branch || 'main'
        };
        
        if (sha) {
            body.sha = sha;
        }
        
        const response = await fetch(url, {
            method: 'PUT',
            headers: {
                'Authorization': `Bearer ${config.token}`,
                'Accept': 'application/vnd.github.v3+json',
                'Content-Type': 'application/json'
            },
            body: JSON.stringify(body)
        });
        
        if (response.ok) {
            const result = await response.json();
            console.log('✅ Запись успешна!');
            console.log('Commit:', result.commit.sha);
        } else {
            const error = await response.json();
            console.log('❌ Ошибка записи:', response.status);
            console.log('Сообщение:', error.message);
        }
    } catch (error) {
        console.log('❌ Ошибка:', error.message);
    }
}

testWrite();
```

```javascript
// Полный тест синхронизации
async function fullTest() {
    console.log('=== ПОЛНЫЙ ТЕСТ СИНХРОНИЗАЦИИ ===\n');
    
    // 1. Проверка localStorage
    console.log('1. Проверка localStorage:');
    const students = localStorage.getItem('rating_students');
    const categories = localStorage.getItem('rating_categories');
    const config = localStorage.getItem('github_config');
    
    console.log('   - Курсанты:', students ? '✅' : '❌');
    console.log('   - Категории:', categories ? '✅' : '❌');
    console.log('   - GitHub config:', config ? '✅' : '❌');
    
    if (!config) {
        console.log('\n❌ GitHub не настроен');
        return;
    }
    
    const cfg = JSON.parse(config);
    
    // 2. Проверка настроек
    console.log('\n2. Проверка настроек GitHub:');
    console.log('   - Владелец:', cfg.owner || '❌');
    console.log('   - Репозиторий:', cfg.repo || '❌');
    console.log('   - Токен:', cfg.token ? '✅' : '❌');
    console.log('   - Файл:', cfg.filePath || 'data.json');
    console.log('   - Ветка:', cfg.branch || 'main');
    
    // 3. Тест соединения
    console.log('\n3. Тест соединения с GitHub:');
    try {
        const url = `https://api.github.com/repos/${cfg.owner}/${cfg.repo}`;
        const response = await fetch(url, {
            headers: {
                'Authorization': `Bearer ${cfg.token}`,
                'Accept': 'application/vnd.github.v3+json'
            }
        });
        
        if (response.ok) {
            const data = await response.json();
            console.log('   ✅ Соединение работает');
            console.log('   Репозиторий:', data.full_name);
        } else {
            console.log('   ❌ Ошибка:', response.status);
            return;
        }
    } catch (error) {
        console.log('   ❌ Ошибка:', error.message);
        return;
    }
    
    // 4. Проверка файла
    console.log('\n4. Проверка файла data.json:');
    try {
        const url = `https://api.github.com/repos/${cfg.owner}/${cfg.repo}/contents/${cfg.filePath || 'data.json'}`;
        const response = await fetch(url, {
            headers: {
                'Authorization': `Bearer ${cfg.token}`,
                'Accept': 'application/vnd.github.v3+json'
            }
        });
        
        if (response.ok) {
            console.log('   ✅ Файл найден');
        } else if (response.status === 404) {
            console.log('   ⚠️ Файл не найден');
        } else {
            console.log('   ❌ Ошибка:', response.status);
        }
    } catch (error) {
        console.log('   ❌ Ошибка:', error.message);
    }
    
    // 5. Тест записи
    console.log('\n5. Тест записи в GitHub:');
    try {
        if (typeof writeToGitHub === 'undefined') {
            console.log('   ❌ Функция writeToGitHub не найдена');
            return;
        }
        
        const success = await writeToGitHub();
        if (success) {
            console.log('   ✅ Запись успешна');
        } else {
            console.log('   ❌ Запись не удалась');
        }
    } catch (error) {
        console.log('   ❌ Ошибка:', error.message);
    }
    
    console.log('\n=== ТЕСТ ЗАВЕРШЁН ===');
}

fullTest();
```
