# ✅ Быстрое решение проблемы с загрузкой данных

## 🎯 Проблема

Курсанты введены в интерфейс, но при обновлении страницы не отображаются.

## 🔍 Причина

Данные находятся **только в localStorage браузера**, но **не в файле `kursanty.json`** в репозитории.

## 🚀 Решение за 3 шага

### Шаг 1: Экспортируйте данные из браузера

1. Откройте сайт
2. Нажмите **F12** (консоль разработчика)
3. Перейдите на вкладку **Console**
4. Вставьте эту команду:

```javascript
const students = JSON.parse(localStorage.getItem('rating_students') || '[]');
const exportData = { kursanty: students, lastUpdated: new Date().toISOString(), version: "1.0" };
const blob = new Blob([JSON.stringify(exportData, null, 2)], { type: 'application/json' });
const url = URL.createObjectURL(blob);
const a = document.createElement('a');
a.href = url;
a.download = 'kursanty.json';
document.body.appendChild(a);
a.click();
document.body.removeChild(a);
URL.revokeObjectURL(url);
console.log('✅ Файл kursanty.json скачан! Курсантов:', students.length);
```

5. Нажмите **Enter**
6. Файл `kursanty.json` будет скачан

### Шаг 2: Загрузите файл в репозиторий

1. Откройте репозиторий на GitHub
2. Нажмите **"Add file"** → **"Upload files"**
3. Перетащите файл `kursanty.json` или нажмите **"choose your files"**
4. Нажмите **"Commit changes"**
5. Подождите **1-2 минуты** для обновления GitHub Pages

### Шаг 3: Проверьте результат

1. Откройте сайт заново
2. Нажмите **Ctrl+F5** (жёсткое обновление)
3. Курсанты должны появиться!

## 📊 Проверка в консоли

После обновления страницы откройте консоль (F12) и проверьте:

**Должно быть:**
```
📥 Загрузка данных из kursanty.json...
📡 URL для загрузки: https://ваш-username.github.io/ваш-репозиторий/kursanty.json
✅ Загружено курсантов: N
✅ Данные загружены из kursanty.json
```

**Если видите это:**
```
⚠️ Не удалось загрузить kursanty.json, используем localStorage
```

Значит:
- Файл не загружен в репозиторий
- Или GitHub Pages ещё не обновился (подождите ещё)
- Или URL неправильный

## 🔍 Диагностика

### Проверка 1: Файл существует?

Откройте в браузере:
```
https://ваш-username.github.io/ваш-репозиторий/kursanty.json
```

**Должен открыться файл с данными курсантов**

### Проверка 2: Данные в localStorage?

В консоли (F12) введите:
```javascript
const data = localStorage.getItem('rating_students');
console.log('Курсантов в localStorage:', data ? JSON.parse(data).length : 0);
```

**Должно показать количество курсантов**

### Проверка 3: URL правильный?

В консоли (F12) введите:
```javascript
const repoUrl = window.location.origin + window.location.pathname.replace(/\/[^\/]*$/, '');
console.log('URL для загрузки:', repoUrl + '/kursanty.json');
```

**Скопируйте URL и откройте в новой вкладке**

## 🐛 Если не помогло

### Проблема: Файл не скачивается

**Решение:**
- Разрешите скачивание файлов в браузере
- Проверьте настройки безопасности
- Попробуйте другой браузер

### Проблема: Файл не загружается в репозиторий

**Решение:**
- Проверьте права доступа к репозиторию
- Убедитесь, что вы владелец репозитория
- Проверьте размер файла (не должен превышать 1 МБ)

### Проблема: GitHub Pages не обновляется

**Решение:**
- Подождите 5-10 минут
- Проверьте настройки GitHub Pages (Settings → Pages)
- Убедитесь, что ветка `main` выбрана как источник

### Проблема: CORS ошибка

**Решение:**
- Убедитесь, что файл находится в корне репозитория
- Проверьте, что GitHub Pages включён
- Очистите кэш браузера (Ctrl+Shift+Delete)
