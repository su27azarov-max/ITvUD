## 🐛 ЧАСТЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ

### Проблема 1: "GitHub не настроен"

**Причина:** Не введены настройки GitHub

**Решение:**
1. Войдите как преподаватель (пароль: `05072020`)
2. Нажмите кнопку **"⚙️ GitHub"** в панели инструментов
3. Заполните все поля:
   - **Владелец**: ваш username на GitHub (например: `ivanov`)
   - **Репозиторий**: название репозитория (например: `rating-system`)
   - **Token**: ваш Personal Access Token (начинается с `ghp_...`)
   - **Путь**: `data.json` (оставьте по умолчанию)
   - **Ветка**: `main` (оставьте по умолчанию)
4. Нажмите **"Сохранить"**

### Проблема 2: "Неверный токен" (401)

**Причина:** Токен неверный или истёк

**Решение:**
1. Перейдите на https://github.com/settings/tokens
2. Найдите ваш токен для "Rating System"
3. Если токен истёк - создайте новый:
   - Нажмите **"Generate new token (classic)"**
   - Note: `Rating System`
   - Expiration: `90 days` (или No expiration)
   - ✅ Отметьте **`repo`** (полный доступ к репозиториям)
   - Нажмите **"Generate token"**
4. Скопируйте новый токен (начинается с `ghp_...`)
5. Вставьте в настройки GitHub на сайте

### Проблема 3: "Недостаточно прав" (403)

**Причина:** Токен не имеет нужных прав

**Решение:**
1. Перейдите на https://github.com/settings/tokens
2. Нажмите на ваш токен
3. Убедитесь, что отмечен чекбокс **`repo`**
4. Если нет - создайте новый токен с правами `repo`

### Проблема 4: "Репозиторий не найден" (404)

**Причина:** Неправильное имя владельца или репозитория

**Решение:**
1. Откройте ваш репозиторий на GitHub
2. Посмотрите URL: `https://github.com/ВЛАДЕЛЕЦ/РЕПОЗИТОРИЙ`
3. Убедитесь, что в настройках GitHub указано точно так же
4. Проверьте регистр (GitHub чувствителен к регистру!)

**Пример:**
- URL: `https://github.com/ivanov/rating-system`
- Владелец: `ivanov` (НЕ Ivanov, не IVANOV)
- Репозиторий: `rating-system` (НЕ Rating-System)

### Проблема 5: "Файл не найден"

**Причина:** Файл `data.json` не существует в репозитории

**Решение:**

**Вариант 1: Создать файл вручную**
1. Откройте репозиторий на GitHub
2. Нажмите **"Add file"** → **"Create new file"**
3. Имя файла: `data.json`
4. Содержимое:
```json
{
  "students": [],
  "categories": [],
  "lastUpdated": ""
}
```
5. Нажмите **"Commit new file"**

**Вариант 2: Автоматическое создание**
1. Внесите любые изменения в приложении
2. Нажмите **"💾 Сохранить"**
3. Файл создастся автоматически

### Проблема 6: CORS ошибка

**Причина:** GitHub блокирует запросы из-за политики безопасности

**Решение:**
1. Убедитесь, что используете HTTPS (GitHub Pages автоматически использует HTTPS)
2. Очистите кэш браузера: **Ctrl+Shift+Delete**
3. Попробуйте другой браузер
4. Если проблема сохраняется - используйте ручной экспорт/импорт

## 🧪 ПОЛНАЯ ДИАГНОСТИКА

### Введите в консоли браузера:

```javascript
// Полная проверка всех компонентов
async function fullDiagnostic() {
    console.log('=== ПОЛНАЯ ДИАГНОСТИКА ===\n');
    
    // 1. Проверка localStorage
    console.log('1. Проверка localStorage:');
    const students = localStorage.getItem('rating_students');
    const categories = localStorage.getItem('rating_categories');
    const config = localStorage.getItem('github_config');
    
    console.log('   - Курсанты:', students ? '✅' : '❌');
    console.log('   - Категории:', categories ? '✅' : '❌');
    console.log('   - GitHub config:', config ? '✅' : '❌');
    
    // 2. Проверка GitHub настроек
    console.log('\n2. Проверка GitHub настроек:');
    if (config) {
        const cfg = JSON.parse(config);
        console.log('   - Владелец:', cfg.owner || '❌');
        console.log('   - Репозиторий:', cfg.repo || '❌');
        console.log('   - Токен:', cfg.token ? '✅' : '❌');
        console.log('   - Файл:', cfg.filePath || 'data.json');
        console.log('   - Ветка:', cfg.branch || 'main');
    }
    
    // 3. Тест соединения
    console.log('\n3. Тест соединения с GitHub:');
    if (config) {
        const cfg = JSON.parse(config);
        try {
            const url = `https://api.github.com/repos/${cfg.owner}/${cfg.repo}`;
            const response = await fetch(url, {
                headers: {
                    'Authorization': `Bearer ${cfg.token}`,
                    'Accept': 'application/vnd.github.v3+json'
                }
            });
            
            if (response.ok) {
                console.log('   ✅ Соединение работает');
            } else {
                console.log('   ❌ Ошибка:', response.status);
            }
        } catch (error) {
            console.log('   ❌ Ошибка:', error.message);
        }
    }
    
    console.log('\n=== ДИАГНОСТИКА ЗАВЕРШЕНА ===');
}

fullDiagnostic();
```

## 🔄 АЛЬТЕРНАТИВНЫЕ РЕШЕНИЯ

### Если GitHub API не работает, используйте:

#### Вариант 1: Ручной экспорт/импорт
1. На первом устройстве:
   - Внесите изменения
   - Нажмите **"💾 Экспорт"**
   - Сохраните JSON файл

2. На втором устройстве:
   - Нажмите **"📂 Загрузить"**
   - Выберите JSON файл
   - Данные загрузятся

#### Вариант 2: Firebase Realtime Database
- Синхронизация в реальном времени
- Бесплатный тариф: 1 ГБ хранилища
- Инструкция: `FIREBASE_SETUP.md`

#### Вариант 3: Локальное хранение
- Используйте только localStorage
- Данные сохраняются только на одном устройстве
- Экспортируйте данные вручную для переноса
