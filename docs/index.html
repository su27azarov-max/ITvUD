Инструкция для преподавателя

Руководство по заполнению и использованию системы рейтинга

📌 Важно: Данная инструкция предназначена для преподавателей. Следуйте рекомендациям для корректного заполнения рейтинга обучающихся.

Система рейтинга обучающихся позволяет преподавателю отслеживать успеваемость студентов по дисциплине в течение семестра. Рейтинг формируется на основе нескольких критериев оценивания, что обеспечивает объективную и комплексную оценку знаний студентов.

Страница содержит три вкладки:
• «Общий рейтинг» — сводная таблица всех студентов с автоматической сортировкой по убыванию баллов
• «Рейтинг по группам» — фильтрация по учебным группам с дополнительной статистикой
• «Инструкция» — данное руководство по заполнению
Рейтинг складывается из следующих компонентов (максимум 100 баллов):

• Посещаемость (макс. 30 баллов) — начисляется за регулярное посещение занятий. 2 балла за каждое занятие (макс. 15 занятий). При пропуске без уважительной причины — минус 2 балла.

• Домашние задания (макс. 30 баллов) — оценивается качество и своевременность выполнения домашних заданий. 2 балла за каждое ДЗ (макс. 15 заданий). За несвоевременную сдачу — минус 1 балл.

• Тест 1 (макс. 20 баллов) — промежуточный контроль знаний по первой части курса. Проводится в середине семестра.

• Тест 2 (макс. 20 баллов) — промежуточный контроль знаний по второй части курса. Проводится перед итоговым проектом.

• Итоговый проект (макс. 10 баллов) — комплексная работа, демонстрирующая освоение всех тем курса.
Шаг 1. Подготовка списка студентов
• Откройте файл index.html в текстовом редакторе
• Найдите массив students в секции <script>
• Добавьте записи о студентах в формате:
  { id: номер, fullName: "ФИО", group: "Номер группы",
    attendance: баллы, homework: баллы,
    test1: баллы, test2: баллы, project: баллы }

Шаг 2. Внесение баллов за посещаемость
• После каждого занятия обновляйте значение attendance
• Максимум 2 балла за занятие, не более 30 за семестр
• Сохраните файл и обновите страницу в браузере

Шаг 3. Выставление баллов за домашние задания
• После проверки каждого ДЗ обновляйте значение homework
• Учитывайте как качество, так и своевременность сдачи
• Максимум 30 баллов за все домашние задания

Шаг 4. Внесение результатов тестов
• После проведения тестов обновляйте значения test1 и test2
• Максимум 20 баллов за каждый тест

Шаг 5. Оценка итогового проекта
• После защиты проектов обновляйте значение project
• Максимум 10 баллов за проект

Примечание: После внесения изменений сохраните файл index.html.
Все данные хранятся локально в HTML-файле.
Итоговая оценка выставляется автоматически на основе суммы баллов:

• 90–100 баллов — Отлично (зачёт/экзамен «5»)
• 75–89 баллов  — Хорошо (зачёт/экзамен «4»)
• 60–74 баллов  — Удовлетворительно (зачёт/экзамен «3»)
• Менее 60 баллов — Неудовлетворительно (незачёт/экзамен «2»)

Примечание: Студенты, набравшие менее 60 баллов, допускаются к пересдаче.
• Во вкладке «Рейтинг по группам» можно просматривать успеваемость каждой группы отдельно
• Карточки групп показывают средние, максимальные и минимальные баллы
• Используйте кнопки для быстрого переключения между группами
• При нажатии на карточку группы автоматически открывается её рейтинг
• Группы определяются автоматически по полю "group" в данных студентов
1. Регулярно обновляйте данные — не откладывайте внесение баллов «на потом»
2. Используйте вкладку «Общий рейтинг» для сравнения студентов между группами
3. Обращайте внимание на студентов с низким рейтингом — им может потребоваться дополнительная помощь
4. Сохраняйте копии файла с промежуточными результатами для отслеживания динамики
5. При возникновении спорных ситуаций используйте детализацию по критериям
6. Для экспорта данных используйте функцию печати браузера (Ctrl+P → Сохранить как PDF)
В: Как добавить нового студента?
О: Откройте файл index.html, найдите массив students и добавьте новую запись с уникальным id, ФИО и номером группы.

В: Можно ли изменить баллы после внесения?
О: Да, просто отредактируйте соответствующие значения в массиве students и сохраните файл.

В: Как рассчитывается итоговая оценка?
О: Оценка рассчитывается автоматически как сумма баллов по всем критериям. Шкала: 90-100 — отлично, 75-89 — хорошо, 60-74 — удовлетворительно, менее 60 — неудовлетворительно.

В: Что делать при ошибке в расчётах?
О: Проверьте введённые данные по каждому критерию. Убедитесь, что все значения являются числами и не превышают максимум.

В: Можно ли посмотреть рейтинг предыдущих семестров?
О: Сохраняйте копии файла с именем, содержащим номер семестра (например, rating_spring_2026.html).
