# Инструкции по настройке Firebase для синхронизации данных

## Проблема, которую решает Firebase

Без Firebase изменения, внесённые преподавателем на одном устройстве, не видны на других устройствах. localStorage работает только локально в браузере конкретного устройства.

Firebase Realtime Database решает эту проблему, синхронизируя данные в облаке в реальном времени.

## Шаг 1: Создание проекта Firebase (5 минут)

1. Перейдите на https://console.firebase.google.com/
2. Войдите в свой Google аккаунт
3. Нажмите **"Добавить проект"** (или "Add project")
4. Введите название проекта, например: `rating-system`
5. Можно отключить Google Analytics (не обязательно для нашего проекта)
6. Нажмите **"Создать проект"**
7. Дождитесь создания проекта (около 30 секунд)
8. Нажмите **"Продолжить"**

## Шаг 2: Создание Realtime Database (2 минуты)

1. В левом меню консоли Firebase найдите раздел **"Build"**
2. Нажмите **"Realtime Database"**
3. Нажмите **"Создать базу данных"** (Create Database)
4. В диалоге выбора региона выберите **"europe-west1"** (или ближайший к вам)
5. Выберите **"Начать в тестовом режиме"** (Start in test mode)
   - Это разрешит чтение и запись без аутентификации
   - Для продакшена позже можно настроить правила безопасности
6. Нажмите **"Включить"** (Enable)

## Шаг 3: Получение конфигурации Firebase (2 минуты)

1. В левом верхнем углу нажмите на шестерёнку ⚙️ рядом с "Обзор проекта"
2. Выберите **"Настройки проекта"** (Project settings)
3. Прокрутите страницу вниз до раздела **"Ваши приложения"** (Your apps)
4. Нажмите на иконку **веб-приложения** `</>`
5. В поле "Название приложения" введите: `rating-web`
6. **НЕ** отмечайте "Также настроить Firebase Hosting"
7. Нажмите **"Зарегистрировать приложение"** (Register app)
8. Появится блок с кодом JavaScript. Найдите объект `firebaseConfig`:

```javascript
const firebaseConfig = {
  apiKey: "AIzaSy...",
  authDomain: "your-project.firebaseapp.com",
  databaseURL: "https://your-project-default-rtdb.europe-west1.firebasedatabase.app",
  projectId: "your-project",
  storageBucket: "your-project.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123456789:web:abc123def456"
};
```

9. **Скопируйте весь объект `firebaseConfig`** — он понадобится на следующем шаге

## Шаг 4: Вставка конфигурации в код (1 минута)

1. Откройте файл `docs/index.html` в текстовом редакторе
2. Найдите строку с комментарием:
   ```
   // ВСТАВЬТЕ СЮДА ВАШУ КОНФИГУРАЦИЮ FIREBASE (из шага 3)
   ```
3. Замените плейсхолдеры на ваши значения из `firebaseConfig`:

**Было:**
```javascript
const firebaseConfig = {
    apiKey: "YOUR_API_KEY",
    authDomain: "YOUR_PROJECT.firebaseapp.com",
    databaseURL: "https://YOUR_PROJECT-default-rtdb.firebaseio.com",
    projectId: "YOUR_PROJECT",
    storageBucket: "YOUR_PROJECT.appspot.com",
    messagingSenderId: "YOUR_SENDER_ID",
    appId: "YOUR_APP_ID"
};
```

**Стало (пример):**
```javascript
const firebaseConfig = {
    apiKey: "AIzaSyB1234567890abcdefghijklmnop",
    authDomain: "rating-system.firebaseapp.com",
    databaseURL: "https://rating-system-default-rtdb.europe-west1.firebasedatabase.app",
    projectId: "rating-system",
    storageBucket: "rating-system.appspot.com",
    messagingSenderId: "123456789012",
    appId: "1:123456789012:web:abc123def456ghi789"
};
```

4. Сохраните файл `docs/index.html`

## Шаг 5: Публикация изменений на GitHub (1 минута)

```bash
git add docs/index.html
git commit -m "Добавлена интеграция с Firebase для синхронизации данных"
git push
```

GitHub Pages автоматически пересоберёт сайт через 1-2 минуты.

## Шаг 6: Проверка работы (2 минуты)

1. Откройте сайт на **первом устройстве** (например, компьютер преподавателя)
2. Откройте консоль браузера (F12 → вкладка Console)
3. Вы должны увидеть сообщение: `✅ Firebase инициализирован`
4. Войдите как преподаватель (пароль: `05072020`)
5. Внесите изменения (например, добавьте курсанта или измените баллы)
6. Нажмите **"💾 Сохранить"**
7. Откройте сайт на **втором устройстве** (например, телефон студента)
8. Обновите страницу (F5)
9. Изменения должны появиться автоматически!

## Как это работает

### Синхронизация в реальном времени

1. **Преподаватель вносит изменения** → данные сохраняются в Firebase
2. **Firebase уведомляет все подключённые устройства** об изменениях
3. **Все устройства автоматически обновляют данные** в реальном времени

### Резервное копирование

- Данные также сохраняются в localStorage каждого устройства
- Если Firebase недоступен, система автоматически переключается на localStorage
- При восстановлении связи данные синхронизируются

### Безопасность

Сейчас база данных работает в **тестовом режиме** — любой, кто знает URL, может читать и писать данные.

Для продакшена рекомендуется настроить правила безопасности в Firebase Console:

1. Перейдите в **Realtime Database** → вкладка **"Правила"** (Rules)
2. Замените правила на:

```json
{
  "rules": {
    ".read": true,
    ".write": "auth != null"
  }
}
```

Это разрешит чтение всем, но запись только авторизованным пользователям.

Для полной безопасности можно добавить Firebase Authentication:
- https://firebase.google.com/docs/auth/web/start

## Устранение проблем

### Проблема: "Firebase не инициализирован"

**Решение:**
- Проверьте, что вы правильно скопировали `firebaseConfig`
- Убедитесь, что все поля заполнены (нет `YOUR_...` плейсхолдеров)
- Откройте консоль браузера (F12) и проверьте ошибки

### Проблема: "Ошибка загрузки из Firebase"

**Решение:**
- Проверьте, что Realtime Database создана и включена
- Убедитесь, что выбран "тестовый режим" (или настроены правила)
- Проверьте URL базы данных в `firebaseConfig`

### Проблема: Данные не синхронизируются между устройствами

**Решение:**
- Убедитесь, что на обоих устройствах используется одна и та же конфигурация Firebase
- Проверьте консоль браузера на обоих устройствах
- Обновите страницу (F5) на обоих устройствах
- Проверьте, что на первом устройстве данные сохранены (нажата кнопка "💾 Сохранить")

### Проблема: Старые данные из localStorage перезаписывают новые из Firebase

**Решение:**
- Очистите localStorage в браузере:
  - Откройте консоль (F12)
  - Выполните: `localStorage.clear()`
  - Обновите страницу (F5)

## Стоимость

Firebase Realtime Database имеет **бесплатный тариф Spark**:
- 1 ГБ хранилища
- 10 ГБ передачи данных в месяц
- 100 одновременных подключений

Для небольшого количества курсантов (до 100-200 человек) этого более чем достаточно.
