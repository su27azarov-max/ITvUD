# 🔧 Синхронизация не работает - что делать?

## ⚡ БЫСТРОЕ РЕШЕНИЕ (5 минут)

### 1. Откройте страницу диагностики
Перейдите по адресу:
```
https://ваш-username.github.io/ваш-репозиторий/check-sync.html
```

Или откройте файл `docs/check-sync.html` в браузере.

### 2. Запустите диагностику
Нажмите кнопку **"🔍 Запустить диагностику"**

### 3. Посмотрите результаты
- ✅ Зелёные галочки - всё работает
- ❌ Красные крестики - есть проблемы
- ⚠️ Жёлтые предупреждения - нужно внимание

### 4. Следуйте инструкциям
Если есть ошибки - читайте раздел "Частые проблемы" ниже.

## 🐛 ЧАСТЫЕ ПРОБЛЕМЫ

### Проблема 1: "GitHub не настроен"

**Что делать:**
1. Откройте основной сайт
2. Войдите как преподаватель (пароль: `05072020`)
3. Нажмите кнопку **"⚙️ GitHub"**
4. Заполните все поля:
   - **Владелец**: ваш username на GitHub
   - **Репозиторий**: название репозитория
   - **Token**: ваш токен (начинается с `ghp_...`)
   - **Путь**: `data.json`
   - **Ветка**: `main`
5. Нажмите **"Сохранить"**

### Проблема 2: "Неверный токен"

**Что делать:**
1. Перейдите на https://github.com/settings/tokens
2. Создайте новый токен:
   - Нажмите **"Generate new token (classic)"**
   - Note: `Rating System`
   - Expiration: `90 days`
   - ✅ Отметьте **`repo`**
   - Нажмите **"Generate token"**
3. Скопируйте токен (начинается с `ghp_...`)
4. Вставьте в настройки GitHub на сайте

### Проблема 3: "Репозиторий не найден"

**Что делать:**
1. Откройте репозиторий на GitHub
2. Посмотрите URL: `https://github.com/ВЛАДЕЛЕЦ/РЕПОЗИТОРИЙ`
3. Убедитесь, что в настройках GitHub указано точно так же
4. Проверьте регистр (GitHub чувствителен к регистру!)

### Проблема 4: "Файл не найден"

**Что делать:**
1. Откройте репозиторий на GitHub
2. Нажмите **"Add file"** → **"Create new file"**
3. Имя файла: `data.json`
4. Содержимое:
```json
{
  "students": [],
  "categories": [],
  "lastUpdated": ""
}
```
5. Нажмите **"Commit new file"**

## 🧪 ПРОВЕРКА В КОНСОЛИ БРАУЗЕРА

### Откройте консоль (F12) и введите:

```javascript
// Проверка настроек
const config = JSON.parse(localStorage.getItem('github_config'));
console.log('Настройки GitHub:', config);

// Проверка данных
console.log('Курсантов:', students ? students.length : 0);
console.log('Категорий:', categories ? categories.length : 0);

// Тест соединения
async function test() {
    if (!config || !config.token) {
        console.log('❌ GitHub не настроен');
        return;
    }
    
    try {
        const url = `https://api.github.com/repos/${config.owner}/${config.repo}`;
        const response = await fetch(url, {
            headers: {
                'Authorization': `Bearer ${config.token}`,
                'Accept': 'application/vnd.github.v3+json'
            }
        });
        
        if (response.ok) {
            console.log('✅ Соединение работает!');
        } else {
            console.log('❌ Ошибка:', response.status);
        }
    } catch (error) {
        console.log('❌ Ошибка:', error.message);
    }
}

test();
```

## 🔄 АЛЬТЕРНАТИВНЫЕ РЕШЕНИЯ

### Если GitHub API не работает, используйте:

#### Вариант 1: Ручной экспорт/импорт
1. На первом устройстве:
   - Внесите изменения
   - Нажмите **"💾 Экспорт"**
   - Сохраните JSON файл

2. На втором устройстве:
   - Нажмите **"📂 Загрузить"**
   - Выберите JSON файл
   - Данные загрузятся

#### Вариант 2: Firebase Realtime Database
- Синхронизация в реальном времени
- Бесплатный тариф: 1 ГБ хранилища
- Инструкция: `FIREBASE_SETUP.md`

#### Вариант 3: Локальное хранение
- Используйте только localStorage
- Данные сохраняются только на одном устройстве
- Экспортируйте данные вручную для переноса
