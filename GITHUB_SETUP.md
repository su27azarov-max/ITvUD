# Инструкции по настройке GitHub API для синхронизации данных

## Проблема, которую решает GitHub API

Без синхронизации изменения, внесённые преподавателем на одном устройстве, не видны на других устройствах. localStorage работает только локально в браузере конкретного устройства.

GitHub API решает эту проблему, синхронизируя данные через облачный репозиторий.

**Преимущества GitHub API:**
- ✅ Бесплатно
- ✅ Работает в России без VPN
- ✅ Надёжное хранилище с версионированием
- ✅ Автоматическое резервное копирование
- ✅ Возможность отслеживать изменения

## Шаг 1: Создание репозитория на GitHub (3 минуты)

1. Перейдите на https://github.com/
2. Войдите в свой аккаунт (или создайте новый)
3. Нажмите **"New"** (Новый репозиторий) в правом верхнем углу
4. Заполните форму:
   - **Repository name**: `rating-system` (или любое другое название)
   - **Description**: `Система рейтинга курсантов` (необязательно)
   - **Public**: ✅ Выберите Public (публичный)
   - **Add a README**: ✅ Отметьте эту опцию
5. Нажмите **"Create repository"**

## Шаг 2: Создание файла data.json (2 минуты)

1. В созданном репозитории нажмите **"Add file"** → **"Create new file"**
2. В поле имени файла введите: `data.json`
3. Скопируйте начальное содержимое из файла `data.json` в корне этого проекта
4. Прокрутите вниз
5. В разделе **"Commit new file"**:
   - Введите сообщение: `Начальные данные рейтинга`
   - Выберите **"Commit directly to the main branch"**
6. Нажмите **"Commit new file"**

## Шаг 3: Создание Personal Access Token (3 минуты)

1. Перейдите на https://github.com/settings/tokens
2. Нажмите **"Generate new token"** → **"Generate new token (classic)"**
3. Заполните форму:
   - **Note**: `Rating System Sync` (описание токена)
   - **Expiration**: Выберите срок действия (рекомендуется 90 дней или Custom date)
   - **Select scopes**: Отметьте **`repo`** (полный доступ к репозиториям)
4. Прокрутите вниз и нажмите **"Generate token"**
5. **ВАЖНО**: Скопируйте токен (начинается с `ghp_...`)
   - Сохраните его в надёжном месте
   - Вы не сможете увидеть его снова!

## Шаг 4: Настройка синхронизации в приложении (2 минуты)

1. Откройте сайт с системой рейтинга
2. Войдите как преподаватель (пароль: `05072020`)
3. Нажмите кнопку **"⚙️ GitHub"** в панели инструментов
4. Заполните поля:
   - **Владелец репозитория**: Ваш username на GitHub (например: `ivanov`)
   - **Название репозитория**: `rating-system` (или то, что вы создали)
   - **Personal Access Token**: Токен, который вы скопировали (начинается с `ghp_...`)
   - **Путь к файлу данных**: `data.json` (оставьте по умолчанию)
   - **Ветка**: `main` (оставьте по умолчанию)
5. Нажмите **"Сохранить"**
6. Система предложит синхронизировать данные - нажмите **"ОК"**

## Шаг 5: Проверка работы (2 минуты)

1. На **первом устройстве** (компьютер преподавателя):
   - Внесите изменения (добавьте курсанта или измените баллы)
   - Нажмите **"💾 Сохранить"**
   - Должно появиться сообщение: `✅ Изменения сохранены в GitHub и локально!`

2. Проверьте на GitHub:
   - Откройте репозиторий `rating-system`
   - Нажмите на файл `data.json`
   - Данные должны быть обновлены

3. На **втором устройстве** (телефон студента):
   - Откройте сайт
   - Нажмите **"🔄 Синхронизация"**
   - Или просто обновите страницу (F5)
   - Изменения должны появиться!

## Как это работает

### Сохранение данных
1. Преподаватель вносит изменения
2. Нажимает "💾 Сохранить"
3. Данные сохраняются в localStorage (локально)
4. Данные отправляются в GitHub через API
5. Файл `data.json` обновляется в репозитории

### Загрузка данных
1. При открытии страницы данные загружаются из GitHub
2. Если GitHub недоступен - из localStorage
3. Все устройства видят актуальные данные

### Синхронизация
- Кнопка "🔄 Синхронизация" принудительно загружает данные из GitHub
- Полезно, если изменения не появились автоматически

## Устранение проблем

### Проблема: "GitHub не настроен"

**Решение:**
- Нажмите "⚙️ GitHub" и заполните все поля
- Убедитесь, что токен начинается с `ghp_`
- Проверьте, что репозиторий существует и публичный

### Проблема: "Ошибка чтения из GitHub"

**Решение:**
- Проверьте правильность имени владельца и репозитория
- Убедитесь, что файл `data.json` существует в репозитории
- Проверьте, что токен имеет права `repo`

### Проблема: "Ошибка записи в GitHub"

**Решение:**
- Проверьте, что токен не истёк
- Убедитесь, что у токена есть права `repo`
- Проверьте, что вы владелец репозитория или имеете права на запись

### Проблема: Данные не обновляются на другом устройстве

**Решение:**
- Нажмите "🔄 Синхронизация" на втором устройстве
- Или обновите страницу (F5)
- Проверьте, что на первом устройстве данные сохранены в GitHub

### Проблема: CORS ошибка в консоли

**Решение:**
- GitHub API поддерживает CORS, но иногда бывают проблемы
- Попробуйте очистить кэш браузера (Ctrl+Shift+Delete)
- Проверьте, что используете HTTPS (GitHub Pages автоматически использует HTTPS)

## Безопасность

### Хранение токена
- Токен хранится в localStorage браузера
- Доступ к нему имеет только текущий браузер
- **Не передавайте токен другим людям!**
- Если токен скомпрометирован - немедленно отзовите его на https://github.com/settings/tokens

### Права токена
- Токен с правами `repo` может читать и писать во все ваши репозитории
- Для большей безопасности можно создать токен только для конкретного репозитория:
  1. При создании токена выберите **"Fine-grained token"**
  2. Укажите только нужный репозиторий
  3. Дайте права только на **"Contents"** (Read and write)

### Публичный репозиторий
- Реппозиторий должен быть публичным для работы без дополнительной аутентификации
- Данные в `data.json` будут видны всем, кто имеет ссылку на репозиторий
- **Не храните конфиденциальные данные в `data.json`**

## Альтернативы

Если GitHub API не подходит, рассмотрите:

1. **Firebase Realtime Database**
   - Синхронизация в реальном времени
   - Бесплатный тариф: 1 ГБ хранилища
   - Инструкция: `FIREBASE_SETUP.md`

2. **Supabase**
   - Открытый исходный код
   - Можно развернуть на своём сервере
   - Бесплатный тариф: 500 МБ

3. **Яндекс Cloud**
   - Работает в России
   - Платный сервис
   - Требует навыков работы с облачными сервисами
