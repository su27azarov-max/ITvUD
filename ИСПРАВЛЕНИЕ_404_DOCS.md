## 📋 Проверка прав токена

Убедитесь, что ваш Fine-grained token имеет следующие права:

| Permission | Значение | Зачем нужно |
|------------|----------|-------------|
| **Contents** | ✅ **Read and write** | Для создания и обновления файлов |
| **Metadata** | ✅ **Read-only** | Для проверки существования файлов |

### Как проверить права токена:

1. Откройте https://github.com/settings/tokens
2. Нажмите на ваш токен
3. Прокрутите вниз до раздела **Repository permissions**
4. Убедитесь, что:
   - **Contents**: Read and write ✅
   - **Metadata**: Read-only ✅

## 🐛 Если ошибка сохраняется

### Ошибка 403 (Forbidden)

**Причина**: Токен не имеет права `Contents: Read and write`

**Решение**:
1. Создайте новый Fine-grained token
2. Укажите право **Contents: Read and write**
3. Используйте новый токен в настройках

### Ошибка 401 (Unauthorized)

**Причина**: Токен недействителен или истёк

**Решение**:
1. Проверьте срок действия токена
2. Создайте новый токен, если нужно
3. Обновите токен в настройках GitHub

### Ошибка 422 (Unprocessable Entity)

**Причина**: Неправильный формат данных или SHA

**Решение**:
1. Очистите localStorage: `localStorage.clear()`
2. Перезагрузите страницу
3. Попробуйте сохранить снова
