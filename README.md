## 🚀 Быстрый старт

### ⚡ Новая упрощённая архитектура

Теперь данные курсантов хранятся в файле **`kursanty.json`** вместо `data.json`. Это устраняет все проблемы с конфликтами версий и упрощает синхронизацию!

### 1. Создайте файл kursanty.json

1. Откройте репозиторий на GitHub
2. Нажмите **"Add file"** → **"Create new file"**
3. Имя файла: `kursanty.json`
4. Вставьте начальное содержимое:
```json
{
  "kursanty": [],
  "lastUpdated": "",
  "version": "1.0"
}
```
5. Нажмите **"Commit new file"**

### 2. Начало работы

1. **Откройте сайт**
   - Перейдите по адресу: `https://ваш-username.github.io/ваш-репозиторий/`

2. **Войдите как преподаватель** (пароль: `05072020`)

3. **Добавьте курсантов**
   - Нажмите **"➕ Добавить"** или **"📥 Импорт"**
   - Введите ФИО и взвод

4. **Начислите баллы**
   - Нажмите **"✏️ Баллы"** рядом с именем курсанта
   - Выберите категорию и введите оценки

5. **Экспортируйте данные**
   - Нажмите **"💾 Экспорт"**
   - Скачается файл `kursanty-2026-01-15.json`
   - Загрузите этот файл в репозиторий как `kursanty.json`

6. **Синхронизируйте на другом устройстве**
   - Откройте сайт на другом устройстве
   - Нажмите **"🔄 Синхронизация"**
   - Данные загрузятся из `kursanty.json`

**Подробная инструкция:** `БЫСТРЫЙ_СТАРТ_KURSANTY.md`

## 📁 Файл kursanty.json

Данные курсантов хранятся в файле `kursanty.json` в корне репозитория.

```json

      "id": 1,

      "group": "1 взвод",

      "reports": 0,
      "bonus": 0,
      "testing": 0,
      "notesGrades": {"3": 0, "4": 0, "5": 0},
```

- ✅ **Простая синхронизация** - экспорт/импорт JSON файлов
- ✅ **Можно редактировать вручную** - через GitHub или текстовый редактор
- ✅ **Надёжная работа** - нет ошибок GitHub API
- ✅ **Совместимость** - поддержка старого формата `data.json`

## 🏆 Шкала оценок

Оценка рассчитывается как процент от максимума основных категорий:

| Процент | Оценка |
|---------|--------|
| ≥90% | Отлично (5) |
| 75-89% | Хорошо (4) |
| 60-74% | Удовлетворительно (3) |
| <60% | Неудовлетворительно (2) |

**Пример:**
- Максимум основных категорий: 1000 баллов
- Студент набрал: 850 баллов
- Процент: 85% → **Хорошо (4)**

## 🔧 Решение проблем

### Проблема: "failed to fetch" при синхронизации

**Решение:** Эта проблема больше не возникает! Система теперь загружает данные напрямую из файла `data.json`, а не через GitHub API.

### Проблема: Данные не загружаются

**Решение:**
1. Проверьте, что файл `data.json` существует в репозитории
2. Проверьте, что GitHub Pages включён
3. Подождите 1-2 минуты после публикации
4. Нажмите **"🔄 Синхронизация"**

### Проблема: Ошибка при сохранении

**Решение:**
1. Проверьте настройки GitHub (кнопка "⚙️ GitHub")
2. Убедитесь, что токен действителен
3. Проверьте права токена (должен быть `repo`)
4. Нажмите **"🔍 Тест"** для проверки соединения

### Проблема: Изменения не видны на другом устройстве

**Решение:**
1. Подождите 1-2 минуты после сохранения
2. Нажмите **"🔄 Синхронизация"** на другом устройстве
3. Или обновите страницу с очисткой кэша (Ctrl+F5)
