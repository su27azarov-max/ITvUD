🔧 Инструкция по настройке GitHub API

💡 Зачем нужен GitHub API?
Без синхронизации изменения, внесённые преподавателем на одном устройстве, не видны на других устройствах. GitHub API решает эту проблему, синхронизируя данные через облачный репозиторий.
✅ Преимущества GitHub API:
  • Бесплатно
  • Работает в России без VPN
  • Надёжное хранилище с версионированием
  • Автоматическое резервное копирование
  • Возможность отслеживать изменения
1 Создание репозитория на GitHub (3 минуты)
  1. Перейдите на github.com
  2. Войдите в свой аккаунт (или создайте новый)
  3. Нажмите "New" (Новый репозиторий) в правом верхнем углу
  4. Заполните форму:
    • Repository name: rating-system
    • Description: Система рейтинга курсантов (необязательно)
    • Public: ✅ Выберите Public (публичный)
    • Add a README: ✅ Отметьте эту опцию
  5. Нажмите "Create repository"
2 Создание файла data.json (2 минуты)
  1. В созданном репозитории нажмите "Add file" → "Create new file"
  2. В поле имени файла введите: data.json
  3. Скопируйте начальное содержимое из файла data.json в корне этого проекта
  4. Прокрутите вниз
  5. В разделе "Commit new file":
    • Введите сообщение: Начальные данные рейтинга
    • Выберите "Commit directly to the main branch"
  6. Нажмите "Commit new file"
3 Создание Personal Access Token (3 минуты)
  1. Перейдите на github.com/settings/tokens
  2. Нажмите "Generate new token" → "Generate new token (classic)"
  3. Заполните форму:
    • Note: Rating System Sync (описание токена)
    • Expiration: Выберите срок действия (рекомендуется 90 дней)
    • Select scopes: Отметьте repo (полный доступ к репозиториям)
  4. Прокрутите вниз и нажмите "Generate token"
  5. ВАЖНО: Скопируйте токен (начинается с ghp_...)
    ⚠️ Сохраните токен в надёжном месте!
    Вы не сможете увидеть его снова!
4 Настройка синхронизации в приложении (2 минуты)
  1. Откройте сайт с системой рейтинга
  2. Войдите как преподаватель (пароль: 05072020)
  3. Нажмите кнопку "⚙️ GitHub" в панели инструментов
  4. Заполните поля:
    • Владелец репозитория: Ваш username на GitHub
    • Название репозитория: rating-system
    • Personal Access Token: Токен, который вы скопировали
    • Путь к файлу данных: data.json (оставьте по умолчанию)
    • Ветка: main (оставьте по умолчанию)
  5. Нажмите "Сохранить"
  6. Система предложит синхронизировать данные - нажмите "ОК"
5 Проверка работы (2 минуты)
  1. На первом устройстве (компьютер преподавателя):
    • Внесите изменения (добавьте курсанта или измените баллы)
    • Нажмите "💾 Сохранить"
    • Должно появиться сообщение: ✅ Изменения сохранены в GitHub и локально!
  2. Проверьте на GitHub:
    • Откройте репозиторий rating-system
    • Нажмите на файл data.json
    • Данные должны быть обновлены
  3. На втором устройстве (телефон студента):
    • Откройте сайт
    • Нажмите "🔄 Синхронизация"
    • Или просто обновите страницу (F5)
    • Изменения должны появиться!

🔄 Как это работает?

Сохранение данных:
  1. Преподаватель вносит изменения
  2. Нажимает "💾 Сохранить"
  3. Данные сохраняются в localStorage (локально)
  4. Данные отправляются в GitHub через API
  5. Файл data.json обновляется в репозитории
Загрузка данных:
  1. При открытии страницы данные загружаются из GitHub
  2. Если GitHub недоступен - из localStorage
  3. Все устройства видят актуальные данные

🛠️ Устранение проблем

Проблема: "GitHub не настроен"
Решение: Нажмите "⚙️ GitHub" и заполните все поля. Убедитесь, что токен начинается с ghp_.
Проблема: "Ошибка чтения из GitHub"
Решение: Проверьте правильность имени владельца и репозитория. Убедитесь, что файл data.json существует.
Проблема: "Ошибка записи в GitHub"
Решение: Проверьте, что токен не истёк и имеет права repo.
Проблема: Данные не обновляются на другом устройстве
Решение: Нажмите "🔄 Синхронизация" или обновите страницу (F5).

🔒 Безопасность

Хранение токена:
  • Токен хранится в localStorage браузера
  • Доступ к нему имеет только текущий браузер
  • Не передавайте токен другим людям!
  • Если токен скомпрометирован - немедленно отзовите его
Публичный репозиторий:
  • Репозиторий должен быть публичным для работы
  • Данные в data.json будут видны всем
  • Не храните конфиденциальные данные!
