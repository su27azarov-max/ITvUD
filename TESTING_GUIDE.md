# Инструкция по тестированию системы рейтинга

## 🧪 Тестовая страница

Создана специальная тестовая страница для проверки работоспособности всех функций системы.

### Как использовать

1. **Откройте тестовую страницу**
   - Перейдите по адресу: `https://ваш-username.github.io/ваш-репозиторий/test.html`
   - Или откройте файл `docs/test.html` локально в браузере

2. **Запустите тесты**
   - Нажмите кнопку "Запустить все тесты" для полной проверки
   - Или запустите отдельные тесты по категориям

3. **Проверьте результаты**
   - ✅ Зелёные сообщения - тест пройден
   - ❌ Красные сообщения - тест не пройден
   - ℹ️ Синие сообщения - дополнительная информация

### Что проверяется

#### Тест 1: Структура данных
- Наличие массивов `students` и `categories`
- Обязательные поля курсантов
- Поля оценок (grades)

#### Тест 2: Расчёт баллов
- Функция `calcTotal()` - суммирование баллов
- Функция `getMaxTotal()` - расчёт максимума
- Функции расчёта оценок
- Функция `getGrade()` - определение оценки

#### Тест 3: Функции отображения
- Рендеринг таблиц
- Получение списка групп
- Функция `ensureStudent()`

#### Тест 4: Модальное окно
- Открытие/закрытие окна
- Работа с оценками
- Работа с баллами

#### Тест 5: Сохранение данных
- localStorage
- Firebase (заглушка)
- GitHub API
- Экспорт/импорт

## 🔍 Проверка в консоли браузера

### Шаг 1: Откройте консоль
1. Откройте сайт в браузере
2. Нажмите **F12** (или Ctrl+Shift+I)
3. Перейдите на вкладку **Console**

### Шаг 2: Проверьте данные
Введите следующие команды:

```javascript
// Проверка количества курсантов
console.log('Курсантов:', students.length);

// Проверка количества категорий
console.log('Категорий:', categories.length);

// Проверка первого курсанта
console.log('Первый курсант:', students[0]);

// Проверка расчёта баллов
console.log('Баллы первого курсанта:', calcTotal(students[0]));

// Проверка максимума
console.log('Максимум:', getMaxTotal());

// Проверка групп
console.log('Группы:', getGroups());
```

### Шаг 3: Проверьте ошибки
- Если есть красные сообщения - это ошибки
- Если есть жёлтые сообщения - это предупреждения
- Если всё зелёное - всё работает правильно

## 📊 Примеры проверки

### Проверка расчёта баллов

```javascript
// Создаём тестового курсанта
const testStudent = {
    id: 999,
    fullName: 'Тестов Курсант',
    group: 'ТЕСТ-001',
    notes: 10,
    practice: 20,
    reports: 15,
    bonus: 5,
    testing: 30,
    notesGrades: {'3': 0, '4': 0, '5': 0},
    practiceGrades: {'3': 1, '4': 1, '5': 1},
    reportsGrades: {'3': 0, '4': 1, '5': 1},
    testingGrades: {'3': 0, '4': 1, '5': 2}
};

// Проверяем расчёт
console.log('Общие баллы:', calcTotal(testStudent));
// Ожидаемый результат: 10 + 20 + 15 + 5 + 30 = 80

// Проверяем расчёт оценок
console.log('Практика:', calcPracticeScore(testStudent.practiceGrades));
// Ожидаемый результат: 1×3 + 1×7 + 1×10 = 20

console.log('Доклады:', calcReportsScore(testStudent.reportsGrades));
// Ожидаемый результат: 0×3 + 1×6 + 1×8 = 14

console.log('Тестирование:', calcTestingScore(testStudent.testingGrades));
// Ожидаемый результат: 0×3 + 1×7 + 2×10 = 27
```

### Проверка определения оценки

```javascript
// Проверяем разные значения
console.log('Оценка за 95 баллов:', getGrade(95).text);
// Ожидаемый результат: "Отлично"

console.log('Оценка за 80 баллов:', getGrade(80).text);
// Ожидаемый результат: "Хорошо"

console.log('Оценка за 65 баллов:', getGrade(65).text);
// Ожидаемый результат: "Удовлетворительно"

console.log('Оценка за 50 баллов:', getGrade(50).text);
// Ожидаемый результат: "Неудовлетворительно"
```

### Проверка групп

```javascript
// Получаем список групп
const groups = getGroups();
console.log('Группы:', groups);
// Ожидаемый результат: ["ИТ-201", "ИТ-202", "ИТ-203"]

// Проверяем количество курсантов в каждой группе
groups.forEach(group => {
    const count = students.filter(s => s.group === group).length;
    console.log(`Группа ${group}: ${count} курсантов`);
});
```

## 🐛 Отладка проблем

### Проблема: Данные не загружаются

**Решение:**
```javascript
// Очищаем localStorage
localStorage.clear();

// Перезагружаем страницу
location.reload();
```

### Проблема: Функции не определены

**Решение:**
```javascript
// Проверяем, загружен ли скрипт
console.log('students:', typeof students);
console.log('categories:', typeof categories);
console.log('calcTotal:', typeof calcTotal);

// Если undefined - скрипт не загружен
// Проверьте путь к файлу index.html
```

### Проблема: Ошибки в консоли

**Решение:**
1. Прочитайте сообщение об ошибке
2. Обратите внимание на номер строки
3. Проверьте код на этой строке
4. Исправьте ошибку
