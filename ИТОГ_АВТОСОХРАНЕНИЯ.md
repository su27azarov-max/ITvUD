## 🔄 Как работает автосохранение?

### Алгоритм:

```
1. Пользователь вносит изменения
   ↓
2. Вызывается markAsChanged()
   ↓
3. Если autoSaveEnabled = true И GitHub настроен:
   ↓
4. Ждём 2 секунды (debounce)
   ↓
5. Автоматически вызываем writeToGitHub()
   ↓
6. Сохраняем данные в docs/kursanty.json
   ↓
7. Показываем уведомление: "✅ Данные автоматически сохранены в GitHub!"
```

### Debounce (задержка):

**Зачем нужна?**
- Предотвращает сохранение при каждом клике
- Уменьшает нагрузку на GitHub API
- Даёт время внести несколько изменений перед сохранением

**Как работает?**
```javascript
if (autoSaveTimer) clearTimeout(autoSaveTimer);
autoSaveTimer = setTimeout(async () => {
    // код сохранения
}, 2000); // 2 секунды
```

Если пользователь вносит изменения быстрее 2 секунд, таймер сбрасывается и отсчёт начинается заново.

## 🔧 Технические детали

### Новые переменные:

```javascript
let autoSaveEnabled = true; // Автосохранение включено по умолчанию
let autoSaveTimer = null; // Таймер для debounce
```

### Модифицированная функция markAsChanged():

```javascript
function markAsChanged() {
    hasChanges = true;
    const btn = document.getElementById('saveBtn');
    if (btn) btn.style.display = '';
    
    // Автосохранение в GitHub с задержкой 2 секунды (debounce)
    if (autoSaveEnabled && isGitHubConfigured()) {
        if (autoSaveTimer) clearTimeout(autoSaveTimer);
        autoSaveTimer = setTimeout(async () => {
            console.log('🔄 Автосохранение в GitHub...');
            showNotification('🔄 Автосохранение в GitHub...');
            try {
                const success = await writeToGitHub();
                if (success) {
                    hasChanges = false;
                    if (btn) btn.style.display = 'none';
                    showNotification('✅ Данные автоматически сохранены в GitHub!');
                }
            } catch (error) {
                console.error('❌ Ошибка автосохранения:', error);
                showNotification('⚠️ Ошибка автосохранения: ' + error.message);
            }
        }, 2000); // Задержка 2 секунды
    }
}
```

### Новая функция toggleAutoSave():

```javascript
function toggleAutoSave() {
    autoSaveEnabled = !autoSaveEnabled;
    const btn = document.getElementById('autoSaveBtn');
    if (btn) {
        if (autoSaveEnabled) {
            btn.textContent = '🔄 Автосохранение: ВКЛ';
            btn.style.background = '#dcfce7';
            btn.style.color = '#166534';
            btn.style.borderColor = '#86efac';
            showNotification('✅ Автосохранение включено');
        } else {
            btn.textContent = '⏸️ Автосохранение: ВЫКЛ';
            btn.style.background = '#fef2f2';
            btn.style.color = '#dc2626';
            btn.style.borderColor = '#fecaca';
            showNotification('⏸️ Автосохранение отключено');
        }
    }
}
```

## 🐛 Решение проблем

### Проблема 1: Автосохранение не работает

**Причина:** GitHub не настроен

**Решение:**
1. Нажмите "⚙️ GitHub"
2. Заполните настройки
3. Нажмите "🔍 Тест"

### Проблема 2: Ошибка при автосохранении

**Причина:** Проблема с GitHub API

**Решение:**
1. Проверьте токен GitHub
2. Убедитесь, что токен имеет права `repo`
3. Попробуйте сохранить вручную

### Проблема 3: Автосохранение слишком частое

**Причина:** Задержка слишком маленькая

**Решение:**
Увеличьте задержку в коде:
```javascript
}, 2000); // Увеличьте до 5000 (5 секунд)
```

### Проблема 4: Автосохранение слишком медленное

**Причина:** Задержка слишком большая

**Решение:**
Уменьшите задержку в коде:
```javascript
}, 2000); // Уменьшите до 1000 (1 секунда)
```
